# 投稿をストーリーズ／リールに展開する手順（2026-10-03）

British Dogs ロンTのフィード投稿（6枚カルーセル）を投稿済み。
これをストーリーズとリールに広げる方法をまとめる。

## 結論

| | そのまま上げられるか |
|---|---|
| **ストーリーズ** | **できる。** 投稿のシェアボタンから30秒 |
| **リール** | **できない。** 同じ写真から別途「作成」する必要がある |

---

## 1. ストーリーズに再シェアする（30秒・まずこれ）

1. 投稿を開く
2. 下の**紙飛行機アイコン**をタップ
3. **「ストーリーズに追加」**
4. 位置とサイズを調整して「ストーリーズ」で公開

### 注意

- **入るのは1枚だけ。** カルーセル6枚全部は入らない
- 投稿が**小さなプレビューカード**になる。全画面にはならない
- タップ先は**投稿**。商品ページには直行しない

→ **フォロワーに「投稿したよ」と知らせる用途**。
これ自体はあまり売れない。無料なので必ずやるが、これで終わりにしない。

---

## 2. 全画面ストーリーズを出す（本番・こちらが売る）

`docs/data/instagram-2026-10/story-britishdogs/` に 1080×1920 を4枚用意した。

| ファイル | 内容 | 貼るスタンプ |
|---|---|---|
| `st-01-sale.png` | 最大50%OFF・全商品・10月31日まで | リンク → `https://sumifofficial.com/collections/all` |
| `st-02-adult.png` | 大人 ¥7,500→¥4,875（35%OFF） | リンク → `https://sumifofficial.com/products/british-dogs-long-sleeve-tee` |
| `st-03-kids-dog.png` | 子ども ¥2,700 ／ 愛犬 ¥3,300（各40%OFF） | リンク×2 → `.../british-dogs-long-sleeve-tee-for-kid` と `.../british-dogs-tank-top-for-dogs` |
| `st-04-size.png` | 愛犬の体重の目安（XS〜L） | リンク → `https://sumifofficial.com/pages/faq` |

**各画像の下380pxは意図的に空けてある。** ここにスタンプを置く。
下に向いた「↓」がスタンプを置く位置の目印。

### 手順

1. ストーリーズ作成 → カメラロールから `st-01` を選ぶ
2. 上部の**スタンプアイコン** → **「リンク」**
3. 上表のURLを貼る → 表示テキストを「ショップを見る」などに変更
4. スタンプを「↓」の下に置く
5. 公開 → 続けて `st-02`〜`st-04` も同様に

### 🔴 商品スタンプではなくリンクスタンプを使う

**商品スタンプは British Dogs 大人が選択肢に出ない**（Meta側の未解決事項）。
リンクスタンプは Meta カタログを経由しないので、この問題を受けない。
Commerce Manager 側が直るまではリンクスタンプで統一する。

### 出す順番

4枚を一度に全部出さない。**1枚目と2枚目を出し、翌日3・4枚目**のほうが
「まだやってる」が伝わる。ハイライトに「SALE」を作って4枚とも入れておく。

---

## 3. リール

**「投稿をリールにする」ボタンは無い。** 同じ写真から新しく作る。

- リール作成 → 写真を複数選択 → 音源を付ける
- ただし**フィードに出したばかりの6枚をそのまま出すと、フォロワーには重複**になる
- 出すなら別の切り口にする。素材は作成済み:
  - `size-guide-1〜6.png`（サイズガイド6枚）
  - 犬種グリッド
  - 他シリーズのコラージュ

**リールは新規リーチ用、ストーリーズは購買導線用。** 役割が違うので兼用しない。

---

## 動画素材について

**このブランドには動画素材が1本も無い**（全部スチル）。
リールを作る場合は静止画のスライドショーになる。
このコンテナには `ffmpeg` が入っていないので、
書き出すなら `imageio-ffmpeg` を入れる必要がある。

## 再出力

`story.html` を編集して `rstory.py` を実行すると4枚とも再出力される。
価格・日付を変えるときはこれを使う。
