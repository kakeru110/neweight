# 商品ページと導線の改善案 2026-10-02

## サイズの寸法表記について

**結論: すでに全商品の説明文に入っている。問題は「見せ方」と「位置」。**

実際に入っている内容（例）:

| 大人用 Tシャツ | 愛犬用 タンクトップ |
|---|---|
| M：着丈71cm、身幅54cm、肩幅50cm<br>L：着丈75cm、身幅58cm、肩幅53cm<br>（女性モデル H161：着用サイズM）<br>（男性モデル H173：着用サイズL） | XS：首回り16cm、着丈26.5cm、胴周り31cm<br>S：首回り18cm、着丈27cm、胴周り37cm<br>M：首回り21cm、着丈30cm、胴周り47cm<br>L：首回り24cm、着丈35cm、胴周り57cm<br>（ヨークシャテリア 3kg：XS）<br>（ジャックラッセルテリア 5kg：S）<br>（ビーグル 8kg：M） |

**内容は十分。愛犬用に犬種と体重の目安まで書いてあるのは強い。**

### 問題（実測）

| | PC | スマホ |
|---|---:|---:|
| 商品ページの高さ | 4,901px | **7,057px** |
| 「Size」が出てくる位置 | 1,150px | **4,636px** |

**スマホでは4,636pxスクロールしないと寸法が出てこない。**
「このサイズで合う？」は買う直前の最大の疑問なのに、ページのほぼ最下部にある。

さらに:
- **寸法が `<br>` の羅列で、表になっていない**（`table` 要素は0個）
- 商品説明の**半分以上がブランド紹介とアーティスト紹介**で、これが**23商品すべてに重複**して入っている

## 改善案（効果の大きい順）

### A. 商品ページに「この絵柄でお揃いに」を入れる ★最優先

**いま、大人用Tシャツのページから愛犬用タンクトップに行く導線がない。**
下部の関連商品4枚はShopifyの自動推薦で、お揃いの組み合わせではない。

Sumifの売りは「3者で同じ絵柄を着る」ことなのに、**サイトがそれを買わせる形になっていない。**

実装は難しくない。`セット:Brittany Spaniel` のような**タグ体系がすでにある**ので、
商品ページで同じシリーズのコレクションを引いて、自分以外の2点を出すだけ。

```
┌────────────────────────────────┐
│ この絵柄でお揃いに                        │
│ [子ども用 ¥2,400] [愛犬用 ¥3,300]       │
└────────────────────────────────┘
```

カートに入れるボタンのすぐ下に置く。

### B. 寸法を表にして、位置を上げる

- `<br>` の羅列 → `<table>` に変換（23商品）
- **ブランド紹介とアーティスト紹介を商品説明から外す**
  → テーマに「追加タブ」機能がある（`product-template` の `show_extra_tab`、いまは `false`）。
    これを使うか、`About Sumif` / `Artist` ページへのリンク1行に置き換える
  → これだけで**商品ページが半分近く短くなり、寸法が上に来る**
- 愛犬用は**体重の目安を先頭に出す**（「3kg前後→XS、5kg前後→S、8kg前後→M」）

### C. フッターの導線を増やす

いまのフッターは Home / Contact / Refund / Terms / Privacy / Tokushoho / Copyright の7本だけ。
**配送・支払い・サイズ・FAQへの導線がない。**

足すもの: 配送について / お支払い方法 / FAQ / Styling Book（大人・子ども・愛犬）

フッターメニューの編集なので**テーマの公開を待たずに即反映できる。**

### D. 検索結果ページのカードが古い

`templates/search.liquid` が解約済みアプリのスニペット `eosh-search-result-variants` を使っている。
コレクションページは新しいカード（色別・割引率バッジ付き）なのに、検索結果だけ別物。

### E. 関連商品（商品ページ下部4枚）も旧カード

割引率バッジが出ない。`sections/product-recommendations.liquid` が旧スニペットを使っている。

## 実施記録 2026-10-02（A〜E＋送料をすべて実行）

### 送料無料のしきい値 — ¥10,000 → **¥8,000** に変更（実施済み・公開中）

**まず訂正。「送料無料は今ない」は誤りで、`¥10,000以上 送料無料` がすでに有効だった。**
通常送料は国内¥490・海外¥1,200。

問題は、**値下げ後の3点セットがほとんど¥10,000に届かないこと**だった。

| シリーズ | 3点セットの価格帯 | ¥10,000に届くか |
|---|---|---|
| British Dogs Tシャツ | 10,375〜11,250 | ◯ |
| British Dogs シャツ | 20,000 | ◯ |
| **RinTinTin** | **8,000〜9,600** | **×** |
| Flanders Tシャツ | 10,800〜12,550 | ◯ |
| Flanders シャツ | 17,200 | ◯ |
| **Brittany Spaniel** | **8,000〜9,600** | **×** |
| Various dogs | 21,120 | ◯ |

届かない2シリーズが**在庫最大の2つ**（Brittany 217点、RinTinTin 157点）。

¥8,000にした根拠:

| 買い方 | 金額 | ¥8,000に届くか |
|---|---|---|
| 大人＋子ども（最安） | 5,250〜6,300 | × |
| 大人＋愛犬（最安） | 6,000〜7,200 | × |
| **3点セット（全シリーズ最安）** | **8,000〜** | **◯** |

**2点では届かず、3点そろえると必ず届く位置。** 「もう1点」を押す設計。
送料¥490は¥8,000に対して6.1%で吸収できる範囲。

**AOVは未取得**（ShopifyQLの `orders` データセットが使えなかった）。
価格を全面改定した直後なので過去のAOVは参考にならず、セット価格の算術で判断した。

### A. 「この絵柄でお揃いに」— 実装済み（下書き `166270075118`）

`snippets/sumif-matching-set.liquid` を新規作成。同シリーズのコレクションから
自分以外で**在庫のある**商品を出す。対象者はタグ（アダルト/キッズ/ドッグ）で判定。
売り切れたら自動的に消える。

置きたいが、同ファイルは38KBあり全文書き直しは転記ミスで商品ページを壊すリスクが大きい。
価格直後から呼ばれている `snippets/product-unit-price.liquid`（1.2KB）にフックを足した。
結果、**PCでカート追加ボタンの470px上**に出ている。両ファイルに理由をコメントで残した。

### B. 寸法を表に・ブランド紹介を削除 — 実施済み・公開中（23商品）

- `Size` の `<br>` 羅列を `<table>` に
- **ブランド紹介とアーティスト紹介を全23商品から削除**し、
  `Sumifについて` / `アーティストについて` へのリンク1行に置き換え

  （例: ヨークシャテリア 3kg → XS ／ ジャックラッセルテリア 5kg → S ／ ビーグル 8kg → M）

## 追記: 商品ページに割引率を出した（2026-10-02）

### 何が問題だったか

コレクションのカードには赤い「45%」バッジが出るのに、商品ページを開くと
`¥3,025  ~~¥5,500~~` と出るだけで、**何割引なのかが分からず、目立たなかった。**

いま全商品が20〜50%OFFで、しかも**色ごとに割引率が違う**（ピンク50% /
オフホワイト45% / スミクロ40% など）。一番の訴求がページ上で見えていなかった。

### 入れたもの

商品価格の右に赤いバッジ、その下におトク額を出す。

```
¥3,025  ¥5,500  [ 45%OFF ]
¥2,475おトク
```

- `snippets/sumif-price-badge.liquid`（新規）
- 呼び出しは `snippets/product-unit-price.liquid` 経由。
  `product-template.liquid` は872行/38KBあって触るのが危ないので、
  その中の `.product-single__prices` から呼ばれている1.2KBのスニペットに相乗りした。

### 色を変えたときの追従（ハマったところ）

**最初の実装は間違っていた。** テーマが出力する `ProductJson-*` から
`select[name=id]` の値でバリアントを引く方式にしたが、
**売り切れサイズがある商品ではテーマが value を空にする**ため
バリアントIDが取れず、色を変えても割引率が前の色のまま残った。

実測:
```
オフホワイト → スミクロ に変更
  価格: ¥3,025 → ¥3,300（正しく更新）
  バッジ: 45%OFF → 45%OFF（更新されず。正しくは40%OFF）
```

**直した方式**: バリアントIDに依存せず、`#ProductPrice` と `#ComparePrice` の
**表示されている金額そのもの**から計算する。テーマの `option_selection.js` は
この2つを必ず書き換えるので確実に追従する。MutationObserverで両方を監視。

### 検証結果（下書きテーマ 166270796014）

Rintintin 半袖Tシャツ（3色とも割引率が違う）で全色を往復:

| 色 | 価格 | 定価 | バッジ | おトク額 |
|---|---|---|---|---|
| オフホワイト | ¥3,575 | ¥6,500 | 45%OFF | ¥2,925おトク |
| スミクロ | ¥3,900 | ¥6,500 | 40%OFF | ¥2,600おトク |
| ピンク | ¥3,250 | ¥6,500 | 50%OFF | ¥3,250おトク |

- 色を往復しても毎回正しい値に戻る（オフホワイト→スミクロ→オフホワイト→スミクロ で確認）
- サイズを売り切れの `L` に変えてもバッジは消えない
- `#ComparePrice` に `hide` が付く（＝定価販売）ケースでは、バッジとおトク額の
  両方が自動で消えることを確認
- 小数2桁の通貨（$20.50 など）では率だけ出し、おトク額は出さない安全弁を入れてある

### 送料無料の表記が10,000円のままだった件

ユーザーがポリシーを8,000円に直したのに、商品ページだけ
「全国一律送料490円（10,000円以上ご購入で送料無料）」と出ていた。

**ポリシー側は正しく直っていた**（APIで配送ポリシー・利用規約の両方を確認済み）。
残っていた10,000円は**別物**で、テーマの翻訳ファイルに直書きされていた:

`locales/ja.json` → `products.general.shipping_policy_html`

```
変更前: 全国一律送料490円（10,000円以上ご購入で送料無料）
変更後: 全国一律送料490円（8,000円以上ご購入で送料無料）
```

この文言は Shopify管理画面の **設定 → 言語 → テーマの言語を編集 → 商品** からも
編集できる。今後また送料条件を変えるときはここも直すこと。
