# 商品ページと導線の改善案 2026-10-02

## サイズの寸法表記について

**結論: すでに全商品の説明文に入っている。問題は「見せ方」と「位置」。**

実際に入っている内容（例）:

| 大人用 Tシャツ | 愛犬用 タンクトップ |
|---|---|
| M：着丈71cm、身幅54cm、肩幅50cm<br>L：着丈75cm、身幅58cm、肩幅53cm<br>（女性モデル H161：着用サイズM）<br>（男性モデル H173：着用サイズL） | XS：首回り16cm、着丈26.5cm、胴周り31cm<br>S：首回り18cm、着丈27cm、胴周り37cm<br>M：首回り21cm、着丈30cm、胴周り47cm<br>L：首回り24cm、着丈35cm、胴周り57cm<br>（ヨークシャテリア 3kg：XS）<br>（ジャックラッセルテリア 5kg：S）<br>（ビーグル 8kg：M） |

**内容は十分。愛犬用に犬種と体重の目安まで書いてあるのは強い。**

### 問題（実測）

| | PC | スマホ |
|---|---:|---:|
| 商品ページの高さ | 4,901px | **7,057px** |
| 「Size」が出てくる位置 | 1,150px | **4,636px** |

**スマホでは4,636pxスクロールしないと寸法が出てこない。**
「このサイズで合う？」は買う直前の最大の疑問なのに、ページのほぼ最下部にある。

さらに:
- **寸法が `<br>` の羅列で、表になっていない**（`table` 要素は0個）
- 商品説明の**半分以上がブランド紹介とアーティスト紹介**で、これが**23商品すべてに重複**して入っている

## 改善案（効果の大きい順）

### A. 商品ページに「この絵柄でお揃いに」を入れる ★最優先

**いま、大人用Tシャツのページから愛犬用タンクトップに行く導線がない。**
下部の関連商品4枚はShopifyの自動推薦で、お揃いの組み合わせではない。

Sumifの売りは「3者で同じ絵柄を着る」ことなのに、**サイトがそれを買わせる形になっていない。**

実装は難しくない。`セット:Brittany Spaniel` のような**タグ体系がすでにある**ので、
商品ページで同じシリーズのコレクションを引いて、自分以外の2点を出すだけ。

```
┌────────────────────────────────┐
│ この絵柄でお揃いに                        │
│ [子ども用 ¥2,400] [愛犬用 ¥3,300]       │
└────────────────────────────────┘
```

カートに入れるボタンのすぐ下に置く。

### B. 寸法を表にして、位置を上げる

- `<br>` の羅列 → `<table>` に変換（23商品）
- **ブランド紹介とアーティスト紹介を商品説明から外す**
  → テーマに「追加タブ」機能がある（`product-template` の `show_extra_tab`、いまは `false`）。
    これを使うか、`About Sumif` / `Artist` ページへのリンク1行に置き換える
  → これだけで**商品ページが半分近く短くなり、寸法が上に来る**
- 愛犬用は**体重の目安を先頭に出す**（「3kg前後→XS、5kg前後→S、8kg前後→M」）

### C. フッターの導線を増やす

いまのフッターは Home / Contact / Refund / Terms / Privacy / Tokushoho / Copyright の7本だけ。
**配送・支払い・サイズ・FAQへの導線がない。**

足すもの: 配送について / お支払い方法 / FAQ / Styling Book（大人・子ども・愛犬）

フッターメニューの編集なので**テーマの公開を待たずに即反映できる。**

### D. 検索結果ページのカードが古い

`templates/search.liquid` が解約済みアプリのスニペット `eosh-search-result-variants` を使っている。
コレクションページは新しいカード（色別・割引率バッジ付き）なのに、検索結果だけ別物。

### E. 関連商品（商品ページ下部4枚）も旧カード

割引率バッジが出ない。`sections/product-recommendations.liquid` が旧スニペットを使っている。

## 確認が必要なこと

- **送料無料のしきい値があるか。** あるなら「あと◯円で送料無料」をカートに出したい（未確認）
- 「追加タブ」を使う場合、タブに出す内容をどうするか（About Sumif ページをそのまま出すか、専用の文章を書くか）
