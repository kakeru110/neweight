## 追加（2026-09-30）: 全23商品の1枚目を切り出し直し、サイズ感を統一

ユーザー指示:
> 1カテゴリーは母親入っててもいいよ。切り出して。
> それと他の22件もそうだけど、人または商品が1番魅力的に見えるサイズに切り出して、サイズ感を統一して。

### 前提の確認: テーマは 5:6（0.833）で表示している

実機のDOMを調べたところ、商品カードは **縦横比 0.833 / `object-fit: fill`** で描画される。
`fill` なので比率の違う画像を入れると**引き伸ばされて歪む**。
既存写真が 1500×1800（＝0.833）だったため今まで問題が出ていなかっただけ。

→ **切り出しは必ず 5:6 にする。**4:5 にすると歪む。

### 切り出し規則（実測に基づく）

23枚すべてにグリッドを重ねて、被写体の座標を実測した。

| 対象 | 規則 |
|---|---|
| 人（大人・キッズ） | **頭頂〜服の裾が画面高さの70%**を占める。頭頂は上から9% |
| 犬 | **体高が画面高さの78%**を占める。体幅は画面幅の88%まで |

拡大はせず、元画素のまま切り出している（画質劣化なし）。
最小でも 578×694px あり、テーマが実際に配信するサイズ（231×278、Retinaで462×556）を上回る。

### British Dogs 長袖シャツ キッズ

ユーザー判断で**母親が写り込んでよい**ことになったため、
家族写真から**子どもを主役にして切り出した**（母親の袖が右に入る）。
これで23件すべてが「主役が明確な1枚目」になった。

### 作業手順

1. 現在の1枚目23枚をCDNから取得
2. 実測値をもとに5:6で切り出し（`scratchpad/crop.py`）
3. `stagedUploadsCreate` → 23枚をGCSへPOST（全件201）
4. `productCreateMedia` で各商品に登録（alt付き）
5. `productReorderMedia` で position 0 へ
6. 公開APIで23/23件の反映を確認、実機（スマホ・DPR2）で目視確認

**元の写真は削除していない。**切り出し版が1枚目に増えただけなので、
戻したい場合は元の写真を position 0 に移すだけでよい。

### 途中で見つけて直したミス

犬22（Two of a kind）の体の左端を 0.28 と実測していたが、正しくは **0.02**。
最初の切り出しで**犬の頭が完全に切れていた**。測り直して修正した。

最終状態: `scratchpad/chk/cropped23.jpg` / 実機 `scratchpad/m_final.png`

## 追記6（2026-09-30）v4 — 横位置のズレの原因究明と、測定ベースへの切り替え

### ユーザー指摘
> 直ってない。添付はすごい左によってる。原因なに？
> 人の場合画像のセンターに頭のセンター合わせればよいんじゃないの？どうやってんの？

指摘どおり。RinTinTin 半袖Tシャツ（アダルト）で女性が大きく左に寄っていた。

### 原因

**被写体の横位置を「目視で見積もった数値」でトリミングしていた。測っていなかった。**

処理の実体は crop.py / crop3.py / crop4.py にあり、そこに手入力の定数表があった。

| スクリプト | 横位置の決め方 | index 6 に入れた値 |
|---|---|---|
| `crop.py` | `PEOPLE[i] = (頭頂, 裾, 中心x)` ← 全部目視 | 中心x = **0.42** |
| `crop3.py` | `OBS[i]` ＝「前の切り出しの中で被写体が何%の位置にいるか」← 目視 | **0.57** |
| `crop4.py` | `per=(頭頂, 裾, 中心x)` ← 目視 | 中心x = **0.60** |

切り出し窓の左端は `left = 中心x × 画像幅 − 窓幅 ÷ 2` で決まる。
**中心xを実際より右に見積もると、窓が右にずれ、その結果 被写体は左に寄る。**

元写真 `fin/06.jpg` の顔の中心を後から機械計測したら **0.501**（＝もともとほぼ中央）。
そこへ 0.42 → 0.57 → 0.60 と誤った値を3回重ねたため、ズレが累積した。

計測値（顔の肌色検出）:

| 版 | 公開画像の顔の中心 | ズレ |
|---|---|---|
| v3（指摘時） | **0.338** | −0.162 |
| v4（修正後） | 0.501 | ±0.00 |

### 直し方（v4）

ユーザーの言うとおりの規則に変えた。**横は測る。目視の数値は一切使わない。**

1. 頭部の帯（頭頂から身長の2%〜20%）だけを走査し、肌色画素の列ヒストグラムを作る
2. 最大の塊＝顔、その左右端の中点を「頭の中心 `hcx`」とする
3. `left = hcx × 画像幅 − 窓幅 ÷ 2` … **頭の中心を画像の中心に合わせる**
4. 縦（頭頂9%・頭〜裾70%）と比率5:6は従来どおり

スクリプト: `crop5.py` ＋ `headx.py`（頭部検出）。
検出が正しいかは、**全14枚に検出線を重ねた確認画像を目視してから**アップロードした
