# トップの商品48枚をシリーズ5枚に置き換え（2026-10-01）

## やったこと

トップページの `featured-collection`（All Items 全48カード）をトップの並びから外し、
代わりに **シリーズ5枚のコレクションタイル** をヒーローの直後に置いた。

| 変更前 | 変更後 |
|---|---|
| ヒーロー → 商品48枚 → GIFバナー → Another line up → GIFバナー | ヒーロー → **シリーズ5枚** → GIFバナー → Another line up → GIFバナー |

## 「大人用しかないように見える」への対応（2026-10-01）

### 案1: タイル名の下に対象を出す — 実装済み

`snippets/collection-grid-item.liquid` を改修。コレクションに入っている商品のタグ
（`アダルト` / `キッズ` / `ドッグ`）を走査して、対象を自動で組み立てる。

```liquid
{%- for cgi_p in collections[featured].products limit: 40 -%}
  {%- if cgi_p.tags contains 'アダルト' -%}{%- assign cgi_adult = true -%}{%- endif -%}
  ...
  {%- if cgi_adult and cgi_kids and cgi_dog -%}{%- break -%}{%- endif -%}
{%- endfor -%}
```

手で書かないので商品が入れ替わってもズレない。表記は `docs/brand-context.md` の
「語り」側（大人・子ども・愛犬）に合わせた。

実測結果:

| タイル | 出力 |
|---|---|
| シリーズ7枚 | 大人・子ども・愛犬 |
| Playing Dog / Two of a kind | **愛犬** |
| Another line up: All Items / Adult / Dog / Kids | 大人・子ども・愛犬 / 大人 / 愛犬 / 子ども |

**スウェット2点が犬専用であることが、初めてトップで伝わるようになった。**

文字サイズは商品カードの色表記と同じ（商品名12.6px / 対象10.5px / opacity .6）。
CSSはスニペット内で1セクションにつき1回だけ出力する（`sumif_tile_style_done` フラグ）。

### 案2: タイル画像を3分割にする — 実寸で検証

**当初「250px幅では小さすぎる」と書いたが、実寸で作ってみたら読めた。前言を訂正する。**

PC 250px・スマホ180pxの実寸で、大人・子ども・愛犬を横3分割に並べたところ、
3者とも顔と柄が判別できる。上下分割（上に大人・下に2つ）は大人の頭が切れるので不可。

  在庫も画像も存在する。Flanders タンクトップ 犬 スミクロは XS/S/M が在庫あり（Lのみ欠品）、
  画像は **`sumif_main_v2_11.jpg`**（1398×1677 / 比0.834）がスミクロ全サイズに割当済み。
