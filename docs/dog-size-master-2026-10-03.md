# 愛犬用 サイズ目安・寸法 一覧（2026-10-03・カタログ照合済み）

公式カタログ2冊（`22AW` / `22SS`）と商品ページを突き合わせた結果。
在庫は **Open Logi 倉庫のみ**。

## ⚠️ 先に訂正

**「シャツの 5kg → M はおそらく誤り」と報告したが、これは間違いだった。**

カタログに **Dog Wear 目安体重** のページ（22AW p10）があり、サイズごとの体重レンジが
公式に定義されていた。

| サイズ | 公式の目安体重 |
|---|---|
| XS | **3〜4 kg** |
| S | **4〜5 kg** |
| M | **5〜8 kg** |
| L | **8〜12 kg** |

> ※体重はあくまでも目安となります。犬種や体型によって異なる場合がございます。

**5kg は S（4〜5）と M（5〜8）の境界**なので、タンクトップの「5kg→S」もシャツの「5kg→M」も
どちらも仕様の範囲内だった。寸法表から「ずれている」と推論したのは誤りで、
実際には体重レンジを見れば両方成立する。

画像は `docs/data/catalog-2026/dogwear-weight-guide.png`。

### 本当の問題はそこではなかった

犬種を1頭ずつ例示する書き方では、**どの体重の子にもSとLが割り当てられない**ことがあった。
公式の体重レンジを載せれば、この穴は構造的に消える。

## 対応したこと（2026-10-03 実施）

愛犬用 **9商品すべて**の説明文に、カタログの公式レンジを入れた。

最初は「XS 3〜4kg ／ S 4〜5kg ／ …」と1行に並べて書いたが、
**スマホで折り返して読みづらかった**（「ジャック／ラッセルテリア」のように語中で改行される）ため、
**体重を寸法表の列に統合**し、着用例は1行1件に分けた。

```
サイズ（cm）
┌──────┬──────────┬───────┬──────┬───────┐
│ サイズ │ 体重の目安 │ 首回り │ 着丈 │ 胴周り │
├──────┼──────────┼───────┼──────┼───────┤
│ XS   │ 3〜4kg   │ 16    │ 26.5 │ 31    │
│ S    │ 4〜5kg   │ 18    │ 27   │ 37    │
│ M    │ 5〜8kg   │ 21    │ 30   │ 47    │
│ L    │ 8〜12kg  │ 24    │ 35   │ 57    │
└──────┴──────────┴───────┴──────┴───────┘

着用例
ヨークシャテリア 3kg → XS
ブリュッセルグリフォン 4.8kg → S
ジャックラッセルテリア 5.2kg → M
ボストンテリア 8.4kg → L

※体重はあくまでも目安となります。犬種や体型によって異なる場合がございます。
```

着用例は**境界にかからない体重だけ**を選んである（5.0kg や 8.0kg のような境界値は使わない）。
スウェット2点だけは XS の例を「ロングコートチワワ 3.3kg」にしてある（実際にその商品を着た写真があるため）。
スウェットは首回りの記載がないので4列になる。

**表示の実測**: PCで表幅306px（説明文の幅625px）、スマホで360px。横スクロールなし。

サイズガイドの画像（投稿②）も2枚目を公式レンジの表に差し替えた。

## 残った確認事項

### ① スウェットのL、胴周り48cm ─ カタログにもそう書いてある

22AW p6（Playing Dog）と p8（Two of a kind）の両方に `36 / 48` と記載されている。
**商品ページの転記ミスではない。** こちらの入力は正しい。

ただし着丈は 27→30→33→36 と3cm刻みで完全に規則的なのに、
胴周りだけ 25→28→31→**48** と最後だけ17cm飛んでいる。
**カタログ側の誤植の可能性は残る**（規則どおりなら34前後）。

Two of a kind の L は **在庫8点**（ホワイト3・ブラック5）あるので、
現物を1枚測れば確定する。測るまでは数字を動かさない。

### ② 犬用シャツの素材 ─ カタログ側の誤りと確定（2026-10-03 ユーザー確認）

カタログでは犬用シャツ3点だけ **Cotton100%** と書かれていたが、
**「大人シャツと犬のシャツは全て同じ素材。PE100%」**とユーザーに確認が取れた。

→ **カタログの誤記。商品ページ（ポリエステル100%）が正しいので変更しない。**

念のためシャツ全6商品の商品ページ表記を確認し、すべて `ポリエステル100%` で統一されていた。

| 商品 | カタログ | 商品ページ | 判定 |
|---|---|---|---|
| British Dogs Long Sleeve Shirts（大人） | PE100% | ポリエステル100% | ✓ |
| 〃 For Kids | PE100% | ポリエステル100% | ✓ |
| British Dogs Shirts For Dog | Cotton100% | ポリエステル100% | **カタログ誤記** |
| Flanders Short Sleeve Shirts（大人） | PE100% | ポリエステル100% | ✓ |
| 〃 For Kids | PE100% | ポリエステル100% | ✓ |
| Flanders Shirts For Dog | Cotton100% | ポリエステル100% | **カタログ誤記** |
| Various dogs Shirts（大人） | PE100% | ポリエステル100% | ✓ |
| 〃 For Kids | PE100% | ポリエステル100% | ✓ |
| Various dogs Shirts For Dog | Cotton100% | ポリエステル100% | **カタログ誤記** |

タンクトップ4点・スウェット2点はカタログも商品ページも Cotton100% / 綿100% で一致。

### ③ マルチマットの裏地 ─ 要確認

`Sumif×TheTENT British Dogs マルチマット`（2026-10-02に公開済み・在庫2点）の商品ページは
**「表 ポリエステル：100%、裏 ポリエステル100%」**。

一方カタログ（22AW p9）の `Sumif×TheTENT Flanders マルチマット` は
**「表：PE100％ 裏：Nylon100％」**。

**別商品（Flanders版 と British Dogs版）**なので直接の矛盾ではないが、同じ作りなら裏はナイロンの可能性がある。
サイズもカタログは 51 / 70、商品ページは 51㎝×69㎝ で1cm違う。
販売中の商品なので、確認が取れれば直す。
