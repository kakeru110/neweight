## 4. 技術メモ: Drive → Shopify の取り込み手順

1. `mcp__Google_Drive__download_file_content` でbase64取得（ツール結果ファイルに退避される）
2. base64をデコードしてローカルに保存
3. `stagedUploadsCreate` でアップロード先を発行
4. 発行されたパラメータで `POST https://shopify-staged-uploads.storage.googleapis.com/`（201が成功）
5. `productCreateMedia` に `originalSource: <resourceUrl>` を渡して商品に紐付け

Shopifyの商品画像は `productCreateMedia` で**末尾に追加**される。
先頭に持ってくる場合は別途並べ替えが必要。
