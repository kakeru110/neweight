# sumif ブランドコンテキスト

> エージェントは外向きの成果物を作る前に必ずこのファイルを読むこと。

## 1. ブランドの核

- **ブランド名**: sumif（サミフ）
- **スタート**: 2022年
- **一行で言うと**: 「大人・子ども・愛犬が、同じデザインで一緒に着られる」ファミリーリンクコーデブランド
- **コンセプト**: 家族の絆を深めるファッション。ペットも家族の一員として扱う。
- **プロダクトの特徴**: アーティストのイラストとの融合。犬をモチーフにしたグラフィック。
- **社会性**: 売上の一部を動物愛護団体へ寄付。
- **ストア**: https://sumifofficial.com （Shopify / JPY / JST）

## 2. sumifが本当に売っているもの

Tシャツではない。**「家族3者（大人・子ども・愛犬）が同じ絵柄で揃う瞬間」**を売っている。

この構造がsumif最大の差別化であり、同時にSNSで最も強い武器になる。
競合の多くは「ペットとお揃い（2者）」までしかやらない。sumifは3者揃う。

→ **すべてのコンテンツ設計は「3者が揃っている画」を中心に置く。**
   単体カットだけの投稿はsumifの強みを捨てている。

## 3. ターゲット

### メイン
- 20代後半〜40代の、犬と暮らす親（特に母親）
- 子どもは110〜130cmサイズ相当（おおよそ3〜9歳）
- 愛犬は小型〜中型（XS〜Lの展開に対応）
- Instagram中心。愛犬アカウント／子育てアカウントをフォロー、または自分でも運用している

### サブ
- 子どもはいないが犬を「うちの子」と呼ぶ夫婦・カップル（大人＋愛犬の2者リンク）
- 出産祝い・誕生日・ペットのお迎え記念のギフト購入層

### インサイト（コンテンツの起点にする）
- 「家族写真を撮りたいけど、毎回バラバラの服で締まらない」
- 「犬にも服を着せたいが、ダサいのは着せたくない／ペットショップの服は世界観が合わない」
- 「子どもとのお揃いは恥ずかしくない範囲でやりたい」
- 「うちの子（犬）を主役にしてあげたい」

## 4. トーン&マナー

### 目指す声
- 穏やか、あたたかい、少し文学的。急かさない。
- 家族の日常の一場面を切り取るような語り口。
- 犬は「ペット」ではなく **「家族」「うちの子」「愛犬」**。
- 主語は「わたしたち」より、読み手（飼い主さん・お父さんお母さん）に寄せる。

### 使う言葉の例
おそろい / リンクコーデ / お散歩 / 休日 / うちの子 / 家族写真 / 一緒に / 並んで / 同じ絵柄

### 使わない言葉・NG表現
| NG | 理由 |
|---|---|
| 「爆売れ」「バズり中」「神商品」 | 世界観と合わない。安く見える |
| 「ペット」単体での連呼 | 家族として扱うブランドの姿勢に反する |
| 「残りわずか！今すぐ！」の連打 | 煽りが強すぎる。限定性は事実だけ静かに書く |
| 「かわいい」だけで終わる説明 | 情報量ゼロ。素材・サイズ・シーンを添える |
| 犬種の優劣・「賢い犬種／飼いやすい犬種」等の序列 | 愛護の姿勢に反する |
| 「1着買えば家族全員分」等の誤認表現 | 大人・キッズ・ドッグは別売り。必ず明示する |
| 断定的な寄付額・寄付率の記載 | 事実確認できない数字は書かない |

### 絵文字
- Instagram: 控えめに可（🐾 🤍 など落ち着いたもの。多用しない、1投稿2〜3個まで）
- X: ほぼ使わない
- 装飾記号の羅列（✨✨✨、‼️）は禁止

## 5. ビジュアルの原則

- 自然光。屋外（公園・散歩道・海辺）または生活感のある室内。
- スタジオの真っ白背景だけで完結させない（家族の日常が消えるため）。
- 犬は必ず「そのままの姿」で。無理なポーズ・過度な擬人化演出はしない。
- 顔出しNGの家族も想定し、後ろ姿・手元・足元・並んで歩くカットのバリエーションを持つ。
- 商品ディテール（プリントの質感、リブ、マジックテープ）のマクロカットを必ず1枚は入れる。

## 6. 表記ルール

- ブランド名は `sumif`（小文字）。文頭でも小文字。ハッシュタグは `#sumif`。
- シリーズ名は英語表記のまま（British Dogs / RinTinTin / Flanders / Brittany Spaniel / Various dogs / Playing Dog / Two of a kind）。
- 価格は税込・円表記（例: ¥6,500）。
- サイズ表記: 大人 M/L、キッズ 110/120/130、ドッグ XS/S/M/L。
- カラー名はストアの表記に従う（オフホワイト / スミクロ / ピンク / グリーン / テラコッタ / 杢グレー 等）。
  「スミクロ」を「ブラック」と書き換えない。

## 7. コンプライアンス

- 景品表示法: 「最安」「日本一」等の最上級表現は根拠なしに使わない。
- 二重価格表示をしない（セール時は元価格の根拠を持つ）。
- ステマ規制: インフルエンサー・アンバサダー投稿には必ず `#PR` または `#sumifアンバサダー` 等、
  関係性が明示される表記を依頼時点で必須条件として伝える。
- UGCの二次利用は、投稿者に個別にDMで許諾を取ってから。無断リポストしない。
- 犬の安全: 着用時の熱中症・誤飲リスクに触れる場面では注意書きを添える。
