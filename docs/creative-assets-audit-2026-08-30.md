## 1. 素材の3層構造

### A層：白背景の商品切り抜き（`DSC01xxx` 系・正方形・2000〜4800px）
Tシャツ・タンクトップ単体を白バックで撮った、いわゆる「物撮り」。

- **SNS単体では弱い。** 世界観も生活も写っていない
- ただし**プリント柄がいちばん鮮明に見える**ので、以下には有効
  - サイズガイド投稿（型E）の比較図
  - カルーセルの2枚目以降「柄のアップ」
  - ストーリーズの商品リンク用サムネ

### B層：スタジオ着用カット（`IMG_xxxx` / UUID系・**1500×1800 縦**）★主力
白壁＋グレーのコンクリ床に、**観葉植物・白いベンチ・ムートン・籐椅子**を置いた統一セット。
大人モデル（男女）、キッズモデルが正面全身で立っている。

- **これがいちばん使える。** 縦1500×1800 = 5:6 で、**Instagramのフィード（4:5）にほぼそのまま載る**
- セットが統一されているのでグリッドが揃う
- 生活感のある小物（籐椅子・ムートン・観葉植物）があり、無菌の白ホリではない
- **顔出しの後ろ姿カットもある**（キッズのバックプリント）→ 顔出しNG層にも刺さる

### C層：犬の着用カット（同じセット）★最強
同じセットで、ジャックラッセルテリアとヨークシャテリアが着用。

- **表情が良く、目線がカメラに来ている**
- 2匹が写っているカットもある
- sumifのアカウントで**最も保存・シェアされるのはこの層**

### 例外：`R_IMG_xxxx` 系（Various dogs）
真っ白バックにスカーフのモデル。**他と世界観が違い、グリッドで浮く**。
Various dogs は在庫も薄いので、当面SNSでは使わない判断でよい。

## 2. 🔴 最大の発見：3者が同じセットで撮られているのに、揃った絵がない

目視した12点のうち、**大人・キッズ・犬すべてが同じ空間**で撮られていることが確認できました。
背景に写り込む小物（観葉植物・白ベンチ・ムートン・籐椅子・コンクリ床）が完全に一致します。

| 素材 | 背景の一致要素 |
|---|---|
| 大人（Brittany Spaniel 男性・女性） | 観葉植物 / 白ベンチ / ムートン / 籐椅子 / コンクリ床 |
| 大人（British Dogs 女性） | 同上 |
| キッズ（Brittany Spaniel 後ろ姿） | 観葉植物 / ベンチ / ムートン |
| キッズ（British Dogs） | ムートン / 観葉植物 |
| **犬2匹（British Dogs シャツ）** | **白ベンチ / ムートン / 観葉植物 / コンクリ床** |

**同じ日・同じセットで撮ったのに、3者を1枚に収めていない。**
sumif最大の武器（他ブランドが作れない「3者が揃う画」）が、撮れる状況にあったのに撮られていません。

### だから今日からできること

**カルーセル（複数枚投稿）で疑似的に並べる。** 背景が同じなので、
1枚目=大人 → 2枚目=キッズ → 3枚目=犬 と送ると、**同じ場所で家族が順に登場する**ように見えます。
切り抜きも合成も不要。**編集コストほぼゼロで「3者リンク」の投稿が作れます。**

## 4. 画像編集か、動画にするか → **静止画カルーセルが先。動画は1つだけ例外**

### 静止画カルーセルを先にすべき理由

- 手持ちが**すべて静止画**。動きのある素材がない
- 静止画を並べただけのスライドショー動画は、リールでは弱い（見られない）
- カルーセルは**保存されやすい**。保存はsumifの最重要KPI
- 編集は「同じセットの3枚を並べる」だけ。**今日できる**

### 唯一やる価値のある動画

**同一セットの3カットを繋ぐトランジション**（大人→キッズ→犬）。
背景が同じなので、切り替わっても場所が変わらず、**服だけが変わっていく**ように見えます。
これは静止画3枚でもリールとして成立する、数少ない型です。10〜15秒。

## 5. 次の撮影で必ず撮るもの（いまの素材に欠けている）

| # | 欠けているカット | なぜ必要か |
|---|---|---|
| 1 | **3者が1枚に収まった引きの絵** | sumif最大の武器。これがないと差別化が伝わらない |

## ただし、判断が必要な点（勝手に決められない）

このルックは**現在のsumifの見え方と全く違います**。

| | ルックブック（2021） | 現在のIG・Shopify |
|---|---|---|
| トーン | **ユーモア／パロディ／少し不穏** | 穏やか・生活感・清潔 |

**どちらが「本当のsumif」なのかは、ブランドの意思決定です。** 私が決めることではありません。

考えられる方針は3つ:

1. **ルックを主役に戻す** — 唯一無二で、他ブランドが真似できない。ただし現在の穏やかなトーンとは断絶する
2. **ブランドストーリー（型F）として限定的に使う** — 「sumifの原点」として紹介。世界観は現在のまま維持
3. **使わない** — 5年前の素材であり、いまのブランドとは違うと判断する

> **1か2を選ぶなら、いま推すべきは British Dogs です。**
