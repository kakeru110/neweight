## 3. どこが詰まっているか

動線は3本ある。いま**3本とも塞がっている。**

| 動線 | 状態 |
|---|---|
| 投稿 → プロフィール → リンク → ストア | グリッドが告知バナーばかりで、商品を着た写真がほぼ無い。入口で止まる |
| **投稿 → 商品タグ → 商品ページ（直行）** | **カタログは繋がっているのに使われていない**（下記） |
| ストーリーズ → リンクスタンプ → ストア | 7月に効いたのはこれ。いまは習慣化されていない |

### 🔴 商品タグが使われていない

**ACTIVE 23商品すべてが、Shopifyの「Facebook & Instagram」チャネルと「Shop」チャネルに
公開済み**であることを確認した（`resourcePublications` で全件 `isPublished: true`）。

つまり**カタログはもうMetaに繋がっている。** にもかかわらず投稿に商品タグが付いていない。

商品タグが付くと、投稿・リール・ストーリーズから**商品ページに直行できる**。
「プロフィールのリンクから飛んでください」という2ステップが消える。

**残っているのはMeta側のInstagramショッピング審査だけの可能性が高い。**
ただしMeta Commerce Managerの状態はShopify側から確認できないため、**要確認**。

確認手順: Instagramアプリ → 設定 → ビジネスツールと管理 → ショッピング
（「ショッピングを設定」と出れば未申請。審査は通常数日）
