# 手順A：有効化されていない場合

> **注意**：Metaの管理画面は頻繁に変わる。以下のメニュー名が実際と違う場合は、
> 「ショッピング」「コマース」「カタログ」で検索する。

## A-1. アカウント種別を確認

Instagram → 設定 → アカウントの種類とツール

**プロフェッショナルアカウント**（ビジネス or クリエイター）である必要がある。
個人アカウントでは商品タグは使えない。

**ビジネスアカウントを推奨。** クリエイターアカウントだと使えない機能がある。

## A-2. Facebookページとの接続

Instagram → 設定 → ビジネスツールと管理 → Facebookページ

sumifのFacebookページと接続されているか確認する。
未接続なら接続する。**接続していないとカタログが紐付かない。**

## A-3. Commerce Manager でカタログを確認

https://business.facebook.com/commerce

- Shopifyから送られたカタログが存在するか
- 商品が「有効」になっているか。「却下」「保留中」があれば理由を見る

**よくある却下理由**：
- 商品画像が無い／不鮮明
- 商品説明が空
- 価格情報の欠落
- リンク先が404

> sumifの23商品は 2026-09-27 時点で画像・説明・alt をすべて整備済み。
> ここで引っかかる可能性は低い。

**在庫0の商品はカタログ上「在庫切れ」になりタグ付けできない。**
2026-09-27時点で24 SKUが0。商品単位では全滅していないので影響は限定的。

## A-4. ドメイン認証（要求された場合）

Meta Business設定 → ブランドセーフティ → ドメイン

`sumifofficial.com` の所有確認を求められることがある。
Shopify経由でカタログを繋いでいる場合は不要なことが多いが、
求められたらDNS TXTレコードかHTMLタグで認証する。

## A-5. ショッピングを申請／有効化

Instagram → 設定 → ビジネスツールと管理 → **ショッピング**

カタログを選択して申請する。
審査は通常数日。却下された場合は理由が通知される。

# 手順B：承認済みの場合（タグ付けの実務）

**ここからが本番。** 承認されていても、投稿ごとに手作業でタグを付けないと意味がない。

## B-1. フィード投稿にタグを付ける

1. 通常どおり投稿を作る
2. キャプション画面で **「商品をタグ付け」**
3. 写真に写っている商品を選ぶ（1投稿に最大5商品、カルーセルは合計20商品）
4. 商品名が写真の上にタグとして乗る

**カルーセルなら1枚ごとにタグを付けられる。**
`docs/instagram-posting-plan-2026-09-27.md` の「型A 揃うカルーセル」は、
1枚目に大人、2枚目に子ども、3枚目に犬用……と**1投稿で3商品に導線が張れる。**

## B-2. ストーリーズにも付ける

ストーリーズ編集画面 → スタンプ → **商品スタンプ**

リンクスタンプより商品スタンプのほうが、商品ページに直接飛ぶ。
週2〜3回のストーリーズで必ず使う。

## B-3. 過去の投稿にも遡って付けられる

既存投稿 → 編集 → 商品をタグ付け

**すでにあるグリッドを一通り見直して、商品が写っているものにタグを付ける。**
新規投稿を増やすより先に、これをやるほうが早い。

---

## 有効化されない・却下される場合

Metaの審査が通らないときの代替。**投稿を止める理由にはならない。**

| 代替策 | 内容 |
|---|---|
| プロフィールのリンク | Linktree等で主要シリーズへの導線を作る |
| ストーリーズのリンクスタンプ | 商品スタンプが使えなくてもURLは貼れる |
| キャプションに誘導文 | 「プロフィールのリンクから」 |

ただし**いずれもワンクッション挟む。** 商品タグの直行性には勝てない。
