# サイト構成の見直し提案 2026-10-02

## 1. 他社の構成（実際に取得して確認した4社）

| ブランド | ナビ | トップの並び |
|---|---|---|
| **Toby & Linus**（人と犬のお揃い、LA） | HOME / ALL / **HUMANS** / **PETS** / **BUNDLES** / ABOUT（6項目・ドロップダウンなし） | コレクションのバナーを縦に積む → 商品グリッド2本 → ニュースレター → ブランドの話 |
| **SAINT RUE**（犬の首輪・リード） | **SHOP ALL / WALK / WEAR**（3項目・ドロップダウンなし） | ヒーロー → 商品4点 → 掲載メディア → 1商品の訴求 → ブランドの考え → CTA → ニュースレター |
| **foufouBRANDS**（犬用品、点数が多い） | Home / New Arrivals / **Shop▾**（カテゴリ・ブランド・コレクションの3軸） / Wholesale / Catalogue / Events | ローンチバナー → ブランド紹介 → 各ブランド3本 → ニュースレター |
| **Everlane**（大手アパレル） | Women / Men / New / Cult Favorites / Clothing / … / **Sale**（最後） | ヒーロー → ブランドの考え → カルーセル → 価格訴求 → カテゴリタイル → 大型タイル → 人気商品 → UGC |

### 読み取れたこと

- **商品点数が少ないブランドほどナビが短く、ドロップダウンがない。**
  Saint Rue は3項目、Toby & Linus は6項目。Sumifは**10項目**ある。
- **お揃い系ブランドは「柄の名前」ではなく「誰が着るか」で切っている。**
  Toby & Linus は `HUMANS` / `PETS` / `BUNDLES`。
  Sumifのナビは `British Dogs` `RinTinTin` `Flanders` `Brittany Spaniel` `Various dogs` と
  **柄の固有名詞が5つ並んでいる。初見の人にはどれも意味がわからない。**
- **「お揃いで買う」導線を独立させている**（Toby & Linus の `BUNDLES`）。
  Sumifの強みはまさにそこなのに、専用の入口がない。
- 大手は `Sale` をナビの最後に置くが、**いまのSumifは全23商品が値引き対象なので先頭でよい。**

## 2. いまのSumifの問題

### ナビ（10項目）

```
SALE / British Dogs / RinTinTin / Flanders / Brittany Spaniel /
Various dogs / All Items▾ / About Sumif▾ / News▾ / Guide▾
```

| # | 問題 |
|---|---|
| 1 | **柄の固有名詞が5つ並んでいる。** 初見の人には選べない |
| 2 | **ナビの5シリーズと、トップの9シリーズタイルが一致していない**（シャツ分割とスウェット2点が入っていない） |
| 3 | `News` の中身は**2022年6月で止まっている**（最新記事が4年前） |
| 4 | `Guide` の親リンクが配送ポリシーに直結していて、親として機能していない |
| 5 | `Artist` のURLが `/pages/test` のまま |

### トップページ（公開中の並び）

```
ヒーロー → セール帯 → シリーズ9枚 → GIFバナー(大人/キッズ/愛犬/全部) →
Another line up(4枚・同じ4つ) → GIFバナー(まったく同じもの)
```

**大人・子ども・愛犬への導線が3回出てくる。** うち2つは完全に同じGIFバナー。

### コレクション（25個）

| 種類 | コレクション |
|---|---|
| **重複** | `Adult` と `アダルト用` / `Kids` と `キッズ用` / `Dog` と `愛犬用ウェア` |

### ページ

- **`Styling Book` という同じ名前のページが3つ**（大人用 / キッズ用 / 犬用）。ナビには1つしか出ていない
- `Animal Donation` と `ピースワンコ` が別ページで内容が重複
- `Contact information` のハンドルが `about-us`、`About Sumif` が `about-us-1` で紛らわしい

## 3. 提案する構成

### ナビ（10項目 → 7項目）

```
SALE
大人     → /collections/adult      （7商品）
子ども   → /collections/kids       （7商品）
愛犬     → /collections/dog        （9商品）
シリーズ ▾ → 9シリーズ
Sumifについて ▾ → About / Artist / 動物保護 / Styling Book
ガイド ▾ → 配送 / 支払い / 返品 / FAQ
```

**根拠**: Toby & Linus と同じく「誰が着るか」を第一階層に出す。
柄の固有名詞は意味を持つ人にしか効かないので、ドロップダウンの中に下げる。
`News` は中身が4年前なので、記事を足すまでナビから外す。

### トップページ（6セクション → 5セクション）

| # | セクション | 役割 | いまとの差 |
|---|---|---|---|
| 1 | ヒーロー（家族写真＋見出し＋CTA） | これが何の店か | そのまま |
| 2 | **セール告知帯** | いま買う理由 | そのまま |
| 3 | **シリーズから選ぶ（9枚）** | 柄で選ぶ | そのまま |
| 4 | **誰が着る（大人／子ども／愛犬 の3枚・大きめ）** | 人で選ぶ | **GIFバナー2本と「Another line up」を1つに統合** |
| 5 | Sumifについて（1段落＋動物保護への言及） | 信頼 | 無効化されている `rich-text` を復活させる |

**削除**: GIFバナー `9859eb6c…` と `24df10f7…`（同一内容が2本）、`Another line up`（4枚）

Toby & Linus も Saint Rue も、トップは **5〜8セクション**で終わっている。
いまのSumifは実質6セクションだが、**そのうち3つが同じことを言っている**のが問題。

### コレクション（25 → 12）

**残す**: `All Items` / `Adult` / `Kids` / `Dog` / 柄5つ（British Dogs, RinTinTin, Flanders, Brittany Spaniel, Various dogs）/ セット分割6つのうち稼働中のもの

**消す候補**:

| コレクション | 理由 |
|---|---|
| `アダルト用` `キッズ用` `愛犬用ウェア` | `Adult` `Kids` `Dog` と完全に重複 |
| `New` | 再入荷のない店に「新着」は意味がない |
| `22 S/S` | 4年前のシーズン |
| `TOP` `ホームページ` `Sumif` | どこからもリンクされていない |
| `Shirt` `T-shirt` | 使っていない。シリーズ側でシャツ/Tシャツは分かれている |

**注意**: 削除前に、どのコレクションがメニュー・テーマ・外部リンクから参照されていないか確認すること。

### ページの整理

- `Styling Book` 3ページ → タイトルを「Styling Book（大人）/（キッズ）/（愛犬）」に変えて区別し、3つともナビに出す
- `Animal Donation` と `ピースワンコ` を1ページに統合
- `/pages/test` → `/pages/artist` にハンドル変更（**リダイレクト設定を忘れずに**）

## 4. やらないほうがいいこと

- **ナビをこれ以上増やさない。** 23商品に10項目は多すぎる
- **「New」を作り直さない。** 売り切りフェーズでは嘘になる
- 検索・絞り込みの強化は後回し。23商品なら全部見たほうが早い
