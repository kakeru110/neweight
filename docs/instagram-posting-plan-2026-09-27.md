# Instagram 継続投稿の設計（2026-09-27）

`docs/instagram-funnel-2026-09-24.md` で「なぜ止まっているか」は出した。
本稿は **何を、どの型で、どの頻度で出し続けるか**。

9/24からの変化: **Drive の写真を商品ページに入れ終わり、素材の全体像が分かった。**
それを踏まえて組み直している。

---

## 0. 投稿を始める前に必ずやること

### Instagram Shopping（商品タグ）を通す

9/24の調査で、**23商品すべてが Facebook & Instagram チャネルに公開済み**
なのに商品タグが使われていないことが分かっている。カタログは繋がっている。
**Meta側の承認が下りていない可能性が高い。**

これが通らないまま投稿を増やしても、**投稿→商品ページの直行路が無いまま**になる。
プロフィールのリンク1本に全部を通すことになり、離脱する。

- Instagram アプリ → 設定 → クリエイター/ビジネスツール → ショッピング
- 審査状況を確認。未申請なら申請、却下ならその理由を潰す

**投稿の設計より先。ここが一番効く。**

## 1. 素材の現実

この写真ライブラリで **作れる型と作れない型** がはっきりしている。

### 作れる

| できること | 根拠 |
|---|---|
| 大人・子ども・犬の「揃う」カルーセル | 4シリーズすべてに、おそろいカットが揃った |
| 色比較（横並び） | Brittany 4色、RinTinTin・Flanders 3色、British Dogs 2色のフラットレイが全色ある |
| 犬のサイズ比較 | 同じ服を複数犬種が着た写真がある（Various dogs は4犬種、RinTinTin は3頭） |
| 背面・ディテール | 9/27に背面カットを各商品に追加済み |
| 静止画スライドのリール | 上記をつなげば作れる |

### 作れない

| できないこと | 理由 |
|---|---|
| 屋外・自然光のライフスタイル写真 | 1枚も無い。全てスタジオ |
| 動画素材 | 1本も無い |
| 「使っている最中」の生活カット | 撮影がEC用途に振り切られている |
| 季節感のある絵 | 背景が全て同じ白壁。季節が出ない |

**結論：既存素材だけで回せるのは「商品を理解させる投稿」。**
**「スクロールを止める投稿」は2枚（British Dogs ルック、Brittany 家族）しか無い。**

この2枚は使い切ると無くなる。**温存せず、ここぞで使う。**

## 2. 投稿の型（6つ）

### 型A：揃うカルーセル（主力・月1〜2回）

1枚目におそろいカット、2枚目以降に大人・子ども・犬の単体、最後に色展開。

| シリーズ | 1枚目に使える素材 |
|---|---|
| Brittany Spaniel | `614D167A` 家族3人＋ビーグル（4色すべてが1枚に写る） |
| Flanders | `1FBA7808` / `382739C2` 飼い主＋犬2頭、`11638DCB` 親子 |
| RinTinTin | `76300926` 飼い主＋ビーグル |
| British Dogs | `36BCF506` 犬が飛びつく、`5F73BCB3` 子どもと犬 |

**売り切りフェーズの主力。** 1投稿で3商品（大人・子ども・犬）に導線が張れる。

### 型B：色比較（月1回）

全色のフラットレイを1枚に並べる、またはカルーセルで1色1枚。

- Brittany Spaniel：4色すべて在庫あり（合計217点）。**最も向いている**
- RinTinTin：オフホワイト21・ピンク21は出せる。**スミクロ3点は出さない**
- Flanders LS Tee：ピンク11点のみ。他2色は合計3点。**色比較には使えない**

### 型C：犬のサイズ（月1回）

**問い合わせが最も多いはずの領域。** 体重とサイズの対応を出す。

使える素材：
- Various dogs Shirts：4犬種が同じ服を着た写真（ただし犬種名は未確定）
- RinTinTin Tank：ジャックラッセル系・ビーグル・ヨークシャテリアの3頭
- Brittany Tank：ヨークシャテリア・ビーグル・小型犬

**注意**：商品説明のモデル犬記載と写真が一致していない箇所がある
（`docs/photo-import-various-dogs-2026-09-27.md` 参照）。
**犬種と体重が確定するまで、断定的な数字は出さない。**

### 型D：背面・ディテール（月1回）

9/27に追加した背面カット、マジックテープ仕様、首元プリントなど。
「買った後に分かること」を先に見せる。返品と問い合わせを減らす。

### 型E：リール（月1〜2回・任意）

静止画のスライドショー。既存素材で作れる。
型Aのカルーセルをそのままリール化するのが最も安い。

**リーチは取れるが、売り切りフェーズでは優先度は低い。**
既に見ている人を買わせるほうが先（`CLAUDE.md`）。

### 型F：ストーリーズ（週2〜3回・必須）

**7月に実際に効いたのはこれ。**

- 商品1点＋リンクスタンプ。それだけでいい
- 在庫が少ないものは出さない（見て買えないのが一番悪い）
- ハイライトに残す：`サイズ` `犬用サイズ` `配送` `シリーズ`

## 5. 🔴 週1投稿だけでは足りない

**自分たちのデータがそう言っている。**

| 月 | Instagram セッション |
|---|---:|
| 6月 | 42 |
| **7月** | **204** |
| 8月 | 23 |
| 9月 | 20 |

7月の山を作ったのは通常投稿ではなく、**`Sumif × NOI` 受注生産という
「名前と日付のある企画」**だった。企画が終われば流入も終わった。

つまり：

- **週次投稿** = 見ている人を逃さないための土台。これだけでは山は作れない
- **四半期に1回の企画** = 山を作る装置。ここで新規が入る

売り切りフェーズで打てる企画の例（いずれも新規仕入れ不要）:

- **シリーズ終了の告知**（再入荷なしは事実。煽らず静かに書く）
- **セット販売**（大人＋犬、大人＋子ども）
- **在庫が残り僅かな色の最終案内**
- **犬の日（11/1）などカレンダー上の日**

> `docs/templates/` にキャンペーン企画書の雛形がある。
> 割引コードの発行は `sumif-campaign-producer` が設計する。

## 6. やらないこと

| やらない | 理由 |
|---|---|
| 在庫の薄い色・サイズを主役にする | 見て買えないのは純粋な機会損失（`CLAUDE.md`） |
| 「残りわずか」で煽る | ブランドのトーンに合わない（`docs/brand-context.md`） |
| ルック写真を商品ページに使う | 2026-09-27 ユーザー指示（`docs/look-vs-product-photo-2026-09-27.md`） |
| 寄付額・寄付先を盛る | 事実ベースのみ（`CLAUDE.md`） |
| 犬種・体重を推測で書く | 未確定の箇所がある |
| 毎日投稿 | 素材が持たない。使い回しはブランドを薄くする |

## 8. 素材が尽きたら

12週回すと、既存素材はほぼ一巡する。その時点で選択肢は3つ。

1. **UGC に切り替える** — 顧客の投稿を許諾を取って使う（`sumif-community-manager`）
2. **撮り直す** — 屋外・自然光・表情のあるカット。確実に効くが新規コスト
3. **同じ写真を別の切り口で使う** — トリミング、寄り、組み合わせ

売り切りフェーズなら **1 → 3 → 2 の順**。
2は「次のブランドフェーズ」の判断とセットで決める話。
