### 案Bを選んだ理由

- 右の3枚が **大人／子ども／愛犬** になっていて、**値引きの告知と同時にブランドの核を見せられる**
- 5:6の商品カットを正方形に切るので顔も柄も切れない（家族写真の横長クロップは必ずどこかが切れる）
- PC198px / スマホ252px。ヒーローとシリーズタイルのどちらも押しつぶさない

### 文字は画像にしていない

写真は画像、**文字はHTML**にした。理由:

- 文字を画像に焼くと、スマホで潰れないように2倍解像度が要る
- 「最大50%」「期限」を変えるたびに画像を作り直すことになる
- 翻訳・読み上げ・検索に乗らない

見た目は画像入りのバナーと変わらない。完全な1枚画像にしたい場合は作り直せる。

## 追記: フォントの原因を特定し、6案を作り直した

### 「AIっぽいフォント」の正体

テーマの見出しフォントは `futura_n4`、本文は `sans-serif`。
**Futura には日本語グリフがないので、和文はブラウザ標準のゴシックに落ちていた。**
だから「全商品 最大50% OFF」が、どのサイトでも見るのっぺりした既定ゴシックで出ていた。

対処: バナー部分だけGoogle Fontsを読む。
- 和文 … `Noto Serif JP`（明朝）
- 数字・英字 … `Oswald` / `Bebas Neue`（コンデンス）

検証で `Noto Serif JP` / `Oswald` / `Bebas Neue` とも実際に適用されることを確認した
（`document.fonts.check` は和文サブセットの都合で false を返すが、描画結果は明朝になっている）。

### 他社調査について

ZOZO / BEAMS / UNITED ARROWS / UNIQLO / 楽天は、
**このコンテナからアクセスがブロックされて閲覧できなかった**（Access Denied または空ページ）。
バナーギャラリー `retrobanner.net` は閲覧できたが、B2B・ゲーム・自動車の広告バナーが中心で
アパレルの参考にならなかった。**他社の実物を見た上での提案ではない**ことを明記しておく。
