## タグの原則

**タグは「時間が経っても変わらない属性」だけに使う。**
在庫数のように動くものはタグにしない — 更新漏れで嘘になり、かえって害になります。
在庫ベースの絞り込みは、Shopifyのスマートコレクションの「在庫数」条件で組みます。

## タグを追加・変更するときのルール

- 既存タグを消さない。`tagsAdd` で追加する（`productUpdate` の tags は**全置換**なので使わない）
- 新しい値を作る前に、この表に載っている値で足りないか確認する（表記ゆれが最大の敵）
- `売り切り` を外すのは、再生産を決めたときだけ
