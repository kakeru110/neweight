## 🔴 商品説明のモデル犬記載と写真が一致しない（未修正）

```

（モデル ジャックラッセルテリア 5kg：着用サイズM）
（モデル ビーグル 8kg：着用サイズM）
```

一方、この商品の写真（既存4点＋Drive 12点＝計16点、全件確認）に写っているのは
**4頭**で、内訳は色と毛質で見ると:

| 写真の犬 | 該当ファイル |
|---|---|
| 白と茶の小型犬（立ち耳・短毛） | 3472 / 3478 / 3482 / 3480 |

**写真は4頭、説明文は3頭。そしてビーグルらしき犬は1頭も写っていない。**

**説明文は変更していない。** 理由は、モデル犬の記載が
「撮影に出た犬」ではなく「試着して採寸した犬」である可能性を否定できないため。
勝手に消すと事実を削ることになる。

判断に必要なのは次の2つ:
1. この4頭の犬種と体重
2. ビーグルの記載は撮影実績か、試着実績か

分かり次第、説明文を正す。

## その他の気づき（未対応）

### 1. 色名が商品間でバラバラ
`色` オプションが存在しないのに、altには色名が入っていた。

- Adult / Kids のalt → **オフホワイト**
- Dog のalt → **クリーム**

同じ生地の同じ商品ラインなので、どちらかに統一すべき。
今回は既存altの表現をそのまま残した（新規追加分には色名を入れていない）。

### 2. ブランド名の表記が `Sumif`
`Various dogs Shirts For Dog` の説明文に `<strong>Sumif</strong>` とある。
`CLAUDE.md` は **「ブランド名 `sumif` は小文字表記（文頭でも `Sumif` にしない）」**。
他の商品にも同じ記述がある可能性が高く、**全商品まとめて直すべき案件**。
今回は範囲外として手を付けていない。

### 3. 在庫が薄い
- **Kids は 120 の 4点のみ。** 110 と 130 は0。実質「ほぼ完売」
- Adult は M が0で L だけ
- Dog は M・L が0で XS・S だけ

**サイズに触れる投稿をする場合は必ず在庫を見ること。**
特に Kids は主役にできる在庫量ではない。
