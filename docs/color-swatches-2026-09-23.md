# カラースウォッチ（色チップ）をテーマに実装した

実施: 2026-09-23 / 対象: Shopify `sumif_official` / テーマ Minimal

---

## 1. 判明したこと: Globoアプリは完全に死んでいた

テーマに **Globo Color Swatch** の設定とファイルが丸ごと残っていた。

- コレクション・商品ページとも「有効」、`色` オプションに5色が**色コード付きで登録済み**
- 描画用のJSファイルも全部テーマ内にある

前回「描画用JSが読み込まれていない」と報告したが、**これは誤りだった。**
ブラウザで実際に再現したところ、**JSは毎ページちゃんと読み込まれていた。**

| 読み込まれていたファイル | サイズ |
|---|---:|
| `globo.swatch.bundle.plugin.*.js` | 135,782 |
| `globo.swatch.bundle.vendors-engine.*.js` | 52,107 |
| `globo.swatch.data.min.js` | 8,756 |
| `globo.swatch.index.min.js` | 2,545 |
| `globo.swatch.bundle.engine.*.js` | 1,666 |
| **合計** | **約 201KB** |

そのうえで何をしていたかというと、**色チップを1つも描画せず、自分の置き場所である
`.swatches-globo--list` を全部DOMから削除していた。**
アプリ本体（課金・サーバー側）がアンインストール済みなので、フロントのJSだけが空回りしていた。

→ **毎ページ約201KBを読んで、マークアップを消すだけの処理をしていた。**

## 2. どうしたか

**アプリを入れ直さず、テーマに直接実装した。** 月額もアプリも不要。

### 追加したファイル

| ファイル | 役割 |
|---|---|
| `snippets/sumif-swatch-card.liquid` | 商品カードの色の丸。**Liquidのみ / JS不要** |
| `snippets/sumif-swatches.liquid` | 共通CSS + 商品ページの色チップ（JS） |

### 変更した既存ファイル（2箇所だけ）

```diff
# snippets/product-grid-item.liquid
-{% include 'swatch-globo' %}
+{% include 'sumif-swatch-card' %}

# layout/theme.liquid
-{{ content_for_header }}{% include 'globo.swatch.script' %}
+{{ content_for_header }}
+（</body> の直前に）{% include 'sumif-swatches' %}
```

Globo関連ファイル自体は**削除していない**。再導入したくなったらincludeを戻すだけでよい。

### 色コードの出どころ

5色は**旧Globoアプリにストアオーナーが登録していた実データ**をそのまま使った。

| 色 | コード | 出どころ |
|---|---|---|
| オフホワイト | `#f8f7ed` | Globoの登録値 |
| スミクロ | `#51545a` | Globoの登録値 |
| ピンク | `#e09ba5` | Globoの登録値 |
| グリーン | `#a4cc74` | Globoの登録値 |
| テラコッタ | `#d68e68` | Globoの登録値 |
| ホワイト | `#ffffff` | **Globoに登録がなかったので名前どおりの値。要調整** |
| ブラック | `#1a1a1a` | **同上** |

ホワイト/ブラックは Two of a kind Sweat と Playing Dog Sweat の2商品で使われている。
実物と合わなければ `sumif-swatches.liquid` と `sumif-swatch-card.liquid` の両方を直す。

未登録の色名が出てきた場合は、**その色のバリアント画像を丸く切り抜いてチップにする**
フォールバックが入っているので、色が消えることはない。

## 3. 仕様

### 商品カード（コレクション / トップページ）

- 商品名・価格の下に色の丸を並べる
- 丸をクリックするとその色の商品ページへ飛ぶ（`?variant=...`）
- **その色が全サイズ売り切れなら斜線**を引き、リンクにしない
- **1色しかない商品には出さない**（ノイズなので）
- Liquidだけで組んでいるので、JavaScriptが動かない環境でも表示される

### 商品ページ

- `色` のプルダウンを、色の丸＋色名のボタンに置き換える
- `サイズ` はプルダウンのまま
- 全サイズ売り切れの色は「スミクロ（売り切れ）」と表示し、斜線を引く
  （選べるようにはしてある。その色が存在したことは伝えたほうがよい）

商品ページはテーマが「1つの`<select>`に全組み合わせ」を出し、
Shopify標準の `option_selection.js` が**実行時に**色・サイズへ分割する作りなので、
サーバー側では組み立てられない。分割が終わるのを待って置き換えている（最大4秒）。

**安全策**: チップの組み立てに成功してから初めて元のプルダウンを隠す。
途中で失敗した場合はプルダウンが残るので、**買えなくなることはない。**

## 4. 検証（実ブラウザで確認済み）

| 項目 | 結果 |
|---|---|
| コレクションの各カードに色の丸が出る | ✅ RinTinTin 3商品すべてに3色 |
| 色コードが正しい | ✅ `rgb(248,247,237)` / `rgb(81,84,90)` / `rgb(224,155,165)` |
| 商品ページで色チップに置き換わる | ✅ サイズはプルダウンのまま |
| チップを押すとバリアントが切り替わる | ✅ variant ID・価格・画像が追随 |
| 押したチップが選択状態になる | ✅（※下記のバグを修正後） |
| 売り切れの色 | ✅ British Dogs のスミクロが「（売り切れ）」＋斜線、押すとボタンが「売り切れ」に |
| Liquidエラー | ✅ 0件 |
| Globoの残骸がDOMを壊していないか | ✅ 読み込み自体がなくなった |

### 途中で見つけて直したバグ

チップを押すと商品は切り替わるのに、**押したチップが選択状態にならなかった。**
原因は、jQueryの `.trigger("change")` が `addEventListener` で登録したハンドラに届かないこと。
逆に素の `dispatchEvent` だけだとjQuery側に届かないため、**両方投げる**ようにして解決した。

## 5. 副次的な効果: ページが軽くなった

Globoの約201KBのJSを読まなくなったうえ、
各商品カードに埋め込まれていた `{{ product | json }}`（商品データ全文）も不要になった。

| ページ | HTMLサイズ 変更前 → 変更後 |
|---|---|
| コレクション（RinTinTin・3商品） | 305KB → **192KB**（−113KB / −37%） |
| 商品ページ | 377KB → **303KB**（−74KB / −20%） |

**HTMLだけで約190KB、JSと合わせると1ページあたり約390KB軽くなった。**

残っているGlobo関連は `globo.swatch.init.js`（**29バイト**、中身は `var globoSwatchInit = true;` のみ）
1本だけ。これはテーマではなくShopifyのScriptTagとして登録されているもので、
今のAPI権限では削除できなかった。実害はない。
