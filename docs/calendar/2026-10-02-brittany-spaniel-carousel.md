### 書き方の根拠（`docs/brand-context.md`）

| 守ったこと | 該当ルール |
|---|---|
| 「そんな日のために作りました」（一着と書かない） | 「1着買えば家族全員分」等の誤認表現NG |
| 「大人・キッズ・ドッグはそれぞれ別売り」を明記 | 同上。**必ず明示する** |
| 「残りが少なくなっています」（煽らない） | 「残りわずか！今すぐ！」の連打NG |
| 「うちの子」「家族写真」を使う | 使う言葉の例 |
| 絵文字は 🐾 ひとつだけ | 1投稿2〜3個まで |
| スミクロをブラックと書かない | カラー名はストア表記に従う |
| 寄付に触れていない | 断定的な寄付額の記載NG。今回は不要なので省いた |
| 「家族写真を撮る日、服がばらばらで締まらない」 | ターゲットのインサイトそのまま |

## 投稿手順（スマホ）

1. 「+」→ 写真を選択 →「選択」で複数選択モードにし、**01〜06の順**で6枚選ぶ
2. 「次へ」→ 編集画面 →「次へ」
3. キャプション欄に上のテキストを貼る
4. **「商品を追加」** →「画像 #」ごとに上の表の商品を選ぶ
5. ハッシュタグをキャプション末尾に貼る（またはコメント欄に投稿）

  **Explore・ハッシュタグ一覧・リールのおすすめから除外される**

  ただしこの点は Instagram が公式に明言していないため、合計5件に収めるのが安全
