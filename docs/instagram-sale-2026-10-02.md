## 1. セールは10月31日まで

これで投稿に期限を書ける。初版で「書けない」としていた制約が外れた。

```

```

### ⚠️ 11月1日に価格を戻す作業が必要

`compareAtPrice` に有効期限はない。**誰かが戻さない限り11月以降もセール価格のまま。**

10月31日の夜か11月1日に戻すこと。忘れるとセール告知が嘘になり、利益も落ちたままになる。

## 3. 「切って貼る」で3者を1枚に

商品画像は大人・子ども・愛犬が**まったく同じスタジオ**（白壁・コンクリ床・観葉植物・籐椅子・
白ベンチ・ムートン）で撮られている。切って並べるだけで、新規撮影なしに3者が1枚に収まる。

**レイアウト（2026-10-02 ユーザー指定）**

```
┌──────────┬──────────┐
│          │  子ども   │
│   大人    ├──────────┤
│          │   愛犬    │
└──────────┴──────────┘
```

左に大人を全身で縦いっぱい、右上に子ども、右下に愛犬。
**左パネルには必ず全身のカットを使う。**寄りのカットを置いた版も作ったが、
子ども・愛犬のカットと距離感が合わず顔だけ大きくなって崩れた。

### 文字・装飾をどこまで入れるか（3案つくって比較した）

写真だけでも成立するが、Instagramは**キャプションを読まずにスクロールされる**ので、
画の中に最低限の情報を入れたほうが効く。

| 案 | 入れたもの |
|---|---|
| a | 「大人／子ども／愛犬」のラベルだけ |
| **b（採用）** | ラベル＋価格（定価取り消し線→販売価格）＋下帯に「シリーズ名／10月31日まで 最大50%OFF」 |
| c | b＋各パネルに赤い %OFF バッジ |

**bを採用した理由**: 見た人が知りたいのは「誰が着られるか」「いくらか」「いつまでか」の3つで、
bはそれを全部静かに答えている。装飾ではなく情報だけを足している形なので、
`brand-context.md` の「煽らない」「装飾記号の羅列をしない」にも触れない。

**cは赤が3つ入る。**フィードでの目立ちは一番だが、穏やかなトーンからは一歩出る。
反応が鈍かったら差し替える、くらいの位置づけ。

**やらないほうがいいこと**: 写真の上に直接白文字を載せる案も作ったが、
背景が白壁とコンクリ床で**どこに置いても読めなかった**。白い箱を敷いて黒文字が正解。

文字の仕様: 和文 Noto Sans JP ／ 欧文・見出し Noto Serif JP、赤は #e8313a。
元データは `collage-deco.html`。価格・日付・画像を差し替えて再出力できる。

## 5. 投稿前にやること

- プロフィールのリンクを `/collections/all`（SALE）に向ける
- 自己紹介に「10月31日まで 最大50%OFF／在庫限り」を1行
- ハイライト「SALE」を新規作成
- トップの帯の文言を「在庫限りです」→「10月31日まで」に変えるか決める
  （テーマエディタのセクション設定から変更できる）

## 6. 書いてはいけないこと

| NG | 理由 |
|---|---|
| 「全商品20〜50%OFF」 | マルチマットが10%OFFなので不正確。「最大50%OFF」と書く |
| 「British Dogs 全部45%OFF」 | 正しくは **35〜45%**。大人の長袖は35% |
| 「大人用はスミクロもあります」 | **大人スミクロは在庫0**。オフホワイトのみ |
| 愛犬用を「長袖」と書く | British Dogs の愛犬用は**タンクトップ**。長袖シャツはM/L欠品で使えない |
| 「1着で家族全員分」 | 3者は別売り |
| 「残りわずか！今すぐ！」 | 煽らない。事実だけ静かに |
| 前回の家族写真の再掲／Brittany Spanielを①に使う | 直前の投稿が同じシリーズ |

### 二重価格表示の根拠

`docs/brand-context.md` §7 に「二重価格表示をしない（セール時は元価格の根拠を持つ）」とある。
