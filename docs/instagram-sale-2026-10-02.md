Brittany Spaniel を選ぶ理由は在庫量だけではない。

1. **3者が1枚に収まった写真が、全商品でこれ1枚しかない**
   `bs_family.jpg` — 父・母・娘・ビーグルが同じ絵柄を着た引きの画。
   `docs/sns-playbook.md` 1.5節には「3者が1枚に収まったカットはない」と書いてあるが、

2. 大人・子ども・愛犬の3者すべてに在庫がある（薄いシリーズが多い中で貴重）
3. 4色展開（オフホワイト／スミクロ／ピンク／グリーン）で画が持つ
4. 3点そろえると必ず送料無料ラインを超える

### 写真の中の組み合わせと、その価格

| | 色 | 定価 | 販売価格 |
|---|---|---:|---:|
| 母 | スミクロ | ¥6,500 | ¥3,900 |
| 父・娘 | オフホワイト | ¥6,500 / ¥4,000 | ¥3,575 / ¥2,200 |
| 愛犬（ビーグル） | グリーン | ¥5,500 | ¥3,300 |

大人スミクロ＋子どもオフホワイト＋愛犬グリーンの3点 = **¥9,400**（定価 ¥16,000）。
送料無料ライン（¥8,000）も超える。

### 最安の3点は ちょうど ¥8,000

ピンクで揃えると 大人¥3,250 + 子ども¥2,000 + 愛犬¥2,750 = **¥8,000**。
定価¥16,000のちょうど半額で、**送料無料ラインぴったり**。これは使える事実。

## 2. 投稿3本立て（1本で終わらせない）

1本の告知投稿だけだと、見た人の「サイズ合うかな」「どれ買えばいいの」で止まる。
告知 → 不安の解消 → 買える形、の3本をセットで出す。

### 投稿2（フィード・カルーセル）— サイズの選び方（型E）

告知の翌日か翌々日。保存されやすく、返品も減る。

### 投稿3（フィード or リール）— RinTinTin ピンクの3点

Brittany Spaniel の次に在庫があり、**ピンクは大人・子ども・愛犬の全サイズが残っている**
（大人 M13 L8 / 子ども 110:8 120:4 130:5 / 愛犬 XS4 S6 M6 L5）。
しかも3点ちょうど¥8,000で、全部50%OFF。「サイズがない」が起きない唯一の構成。

RinTinTin には3者が1枚に収まった写真はないが、**大人＋愛犬のおそろいカットが2枚ある**
（スミクロの女性＋愛犬／スミクロの女性＋ピンクの愛犬）。
これを1枚目に置き、2枚目以降を 大人→子ども→愛犬 と送る。
商品画像はすべて同じスタジオ（白壁・観葉植物・籐椅子）なので並べても違和感がない。

## 4. 書いてはいけないこと

| NG | 理由 |
|---|---|
| 「全商品20〜50%OFF」 | **マルチマットが10%OFFなので不正確になった。**「最大50%OFF」と書く |
| 「45〜50%OFF」(Brittany Spaniel) | 正しくは **40〜50%**。スミクロとグリーンは40% |
| 「期間限定」「◯日まで」 | **終了日を決めていない。** 下記参照 |
| 「1着で家族全員分」 | 3者は別売り。brand-context §4 |
| 子ども120のオフホワイトを主役にする | **在庫0** |
| 愛犬Lのピンク・グリーンを主役にする | **どちらも在庫0** |
| 「残りわずか！今すぐ！」 | 煽らない。事実だけ静かに |

## 5. 先に決めておくべきこと（判断が必要）

### セールの終了日

`compareAtPrice` には期限がない。**誰かが戻さない限り永久にセール価格のまま。**
「いつまでですか」と聞かれても今は答えられず、「期間限定」とも書けない。

- 終了日を決める → 投稿に書ける。駆け込みが発生する
- 決めない → 「在庫限り」としか書けない。訴求は弱いが嘘はつかない

売り切りフェーズなので「在庫限り」で一貫させるのが筋は通っている。どちらにするか決めてほしい。

### 二重価格表示の根拠

`docs/brand-context.md` §7 に「二重価格表示をしない（セール時は元価格の根拠を持つ）」とある。
取り消し線で出している定価（¥6,500 等）が、**直近相当期間に実際にその価格で販売していた**
ことが前提になる。これはこちらでは確認できない。問題があれば表示を見直す。
