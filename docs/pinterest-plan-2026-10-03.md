# Pinterest 運用プラン（2026-10-03）

## 先に、期待値の訂正

前のやりとりで「残り28日ずっと効く」と書いたが、**言い過ぎだった。**

Pinterestはピンが検索に乗るまで**数日〜数週間**かかる。
**10月のセールを救う施策ではない。**

Pinterestの価値は別のところにある。

| | Instagram | Pinterest |
|---|---|---|
| 投稿の寿命 | 2〜3日 | **数ヶ月〜数年** |
| 性質 | タイムライン | **検索エンジン** |
| 流入 | フォロワー中心 | **フォロワー不要** |

**フォロワーがいなくても検索から入ってくる。** フォロワーがほぼいない
いまの状態では、ここが決定的に違う。11月以降も在庫を売り続けるなら、
いま仕込む価値がある。

## すでに終わっていること

**Pinterest販売チャネルは2022-08-03に接続済みで、全商品が公開済み。**
つまり**商品ピンは自動で生成される**仕組みがもう入っている。

→ 今回作るのは、その上に乗せる**アイデアピン（手動）**。

### 🔴 認証先が独自ドメインではない

**認証されているのは `sumif-official.myshopify.com` で、
`sumifofficial.com` ではない。**

サイト側を調べても認証の痕跡（DNS TXT / metaタグ）が無かったのはこのため。
Shopifyの Pinterest アプリが myshopify ドメインのほうを認証したと思われる。

| | |
|---|---|
| リンクは切れるか | **切れない**。`sumif-official.myshopify.com/products/...` は
`sumifofficial.com/products/...` へ **301リダイレクト**する（実測） |
| 何が問題か | **ピンの遷移先 `sumifofficial.com` は未認証ドメイン**。
Pinterestの帰属表示と分析が効かない |

**`docs/traffic-reality-2026-10-03.md` で「Pinterest経由の商品ページ到達数で測る」と
決めたばかりなので、これを直さないと測定できない。**

→ Pinterest の 設定 → 認証済みアカウント で **`sumifofficial.com` を追加で認証する**。
metaタグ方式を選んだ場合は、タグ文字列をもらえれば
`layout/theme.liquid` に入れる（`google-site-verification` の隣）。

## 🔴 セール告知のピンは作らない

**Pinterestのピンは数年残る。** 「10月31日まで」のピンは11月から
**ずっとゴミになる**。しかも古い情報が検索に残り続ける。

セールは**遷移先のページ側で見せる**。
告知バーも商品ページの割引バッジも公開済みなので、
ピンを踏んだ時点でセール中だと分かる。期限が過ぎても矛盾しない。

## Instagramとの違い（間違えやすい点）

| | Instagram | Pinterest |
|---|---|---|
| ハッシュタグ | **5個まで**（上限） | **使わなくてよい**。検索はタイトルと説明文 |
| 画像比率 | 4:5（1080×1350） | **2:3（1000×1500）** |
| 文字入れ | 控えめ | **入れたほうがよい**（検索結果で読まれる） |
| 投稿頻度 | 週2〜3 | 毎日少しずつでも可 |

**Instagram用の4:5画像をそのまま使わない。** 2:3で作り直してある。
