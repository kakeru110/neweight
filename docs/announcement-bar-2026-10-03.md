# トップの告知バーにセール情報を入れた（2026-10-03）

## テーマの標準機能だった

ヘッダー（`sections/header.liquid`）には最初から **告知バー** の仕組みが入っていて、
`show_announcement` が `false` になっているだけだった。新しくコードを書く必要はなかった。

```liquid
{% if section.settings.show_announcement %}
  <div class="header-bar__module header-bar__message">…</div>
{% elsif section.settings.header_search_enable %}
  <div class="header-bar__module header-bar__search">…</div>
{% endif %}
```

左のスロットは「告知」か「検索」の**どちらか**。告知をONにすると、
検索窓は自動的に右側へ移る（後段に別の分岐があるため消えない）。

## 入れた文言

```
10月31日まで 最大50%OFF ／ ¥8,000以上で送料無料
```

リンク先は `/collections/all`（SALE）。

| 変更前 | 変更後 |
|---|---|
| `show_announcement: false` | **`true`** |
| `header_text: ""` | **上記の文言** |
| `announcement_link: ""` | **`/collections/all`** |

変更したのは `config/settings_data.json` の header セクションの3項目だけ。
**セクション設定なので、今後は管理画面のテーマエディタ（ヘッダー → 告知バー）から
日付や文言を直せる。** セール終了後はチェックを外せば消える。

- **スマホ**: 帯の最上段に中央寄せで単独表示。PCより目立つ
- トップページのセクション数（タイル12枚）が変わっていないことを確認

## ⚠️ 書き込み上限のため、無効化済みセクションを2つ削除した

Shopify の GraphQL は**1リクエスト16,384文字**が上限で、
`settings_data.json`（12.7KB）をそのまま送ると18,239文字で**超過して書き込めなかった**。

収めるために、以下を削除した。**いずれも `disabled: true` で表示されていなかったもの。**

| 削除したもの | 中身 | 判断 |
|---|---|---|
| `9859eb6c-cdd2-43a2-b5fc-e909762cd3a5` | 旧ナビのGIFバナー（All Items / 大人 / 子ども / 愛犬） | 無効。シリーズタイルに置き換わり済み |
| `24df10f7-0049-4e48-8fc2-90d1d9e5caca` | **上とまったく同じ内容の重複** | 無効かつ重複 |
| ファイル先頭の自動生成コメント | Shopifyが書く注意書き | 再生成される |

2つは**バイト単位で同一の重複**で、どちらも無効。`content_for_index` からも該当の2行を外した。
復元が必要なら、テーマ `166271353070` の `config/settings_data.json` に残っている。

なお `presets` ブロックは 2026-10-02 の時点で既に欠落している（当時報告済み）。今回も付けていない。
