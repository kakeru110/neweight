## レイアウトの調整記録

グリッドが1350pxに収まらず3回調整した。最終値：

| | 写真の高さ（幅に対する%） |
|---|---|
| 9セル（1枚目） | 86% |
| 9セル＋価格行（4枚目） | 72%。犬は横向きなので横長クロップで成立する |
| 6セル（2・3枚目） | 104% |

4枚目は `kind`（タンクトップ等）を商品名の2行目に統合して1行削った。
