# sumif SNS運用プレイブック

## 0. 前提となる戦略

sumifの勝ち筋は「かわいい服の写真を並べる」ことではない。
**「大人・子ども・愛犬が同じ絵柄で並んだ画」を、他ブランドが真似できない量で出し続ける**ことにある。

したがって全チャネル共通の編集方針は次の3点。

1. **3者が並んだ画を、全投稿の3割以上に入れる**（sumifにしか作れない絵）
2. **飼い主さんの生活が写り込む**（公園、散歩、リビング、車。無菌のスタジオ写真だけにしない）
3. **UGCを主役にする**（お客様の投稿は最強のコンテンツ。ブランド公式写真より信頼される）

### 🔴 現在は「売り切りフェーズ」

**新規入荷は基本的にない。いまある在庫を売り切ることが目的。**
これは通常のブランド運用と前提が違うので、全エージェントが以下を守ること。

| 通常の運用 | sumifの現在 |
|---|---|
| 新作を告知して認知を積む | **今ある在庫を、在庫がある間に売る** |
| 売れ筋を追加生産する | 追加生産はしない。売れたら終わり |
| フォロワーを増やして将来に備える | **今月の売上に効く導線**を優先する |
| 品切れは「人気の証」として使える | 品切れは純粋な機会損失。二度と戻らない |

**運用上の帰結**
- **在庫の多いSKUから順に露出させる。** 「推したいもの」ではなく「捌きたいもの」が優先。
- **品切れサイズを主役にした投稿は、以前にも増して無駄。** 撮影前に必ず在庫を見る。
- **「再入荷なし」は事実なので、静かに書いてよい。** ただし煽らない
  （○「この配色は今ある分で終わりです」／×「残りわずか！急いで！」）。
- **リーチを増やす施策より、既に見ている人を買わせる施策**（サイズガイド、セット導線、
  LINE告知、UGC）のほうが費用対効果が高い。
- 在庫が尽きたシリーズは、コンテンツからも速やかに引き上げる。

## 1. チャネル別の役割分担

| チャネル | 役割 | 主なフォーマット | 投稿頻度の目安 |
|---|---|---|---|
| **Instagram** | 本丸。世界観の蓄積 + 購買導線 | フィード / リール / ストーリーズ | フィード週3・リール週2・ストーリーズ毎日 |
| **TikTok** | 新規リーチ。認知獲得（購入導線は弱い） | 縦動画のみ | 週3〜4（IGリールと共通素材で可） |
| **X (Twitter)** | 一次情報の告知、犬コミュニティとの会話 | テキスト+画像、発売告知 | 週3〜5 |
| **LINE公式** | 既存客の再購入導線 | 発売告知、限定クーポン | 月2〜4 |

> 立ち上げ期にすべて同時に走らせない。
> **Instagram（フィード+リール+ストーリーズ）を最優先で固め、素材の再利用でTikTokに展開**するのが最短。

### TikTokをどう位置づけるか

TikTokは日本で4,200万人規模、30代・40代の利用も伸びており、
「若者だけのSNS」ではなくなっている。sumifのターゲット（犬と暮らす20代後半〜40代の親）に
届かないメディアではない。

**ただしTikTokは「認知」であって「購入」ではない。**
単価¥4,000〜12,000のアパレル、しかも大人・キッズ・ドッグを揃えると1万〜2万円になる買い物は、
TikTokの発見面から即決されにくい。TikTokの役割は次の一点に絞る。

> **「大人と子どもと犬が、同じ絵柄で揃う」という概念をまだ知らない人に見つけてもらう。**
> 買うのは、そこからInstagramやサイトに来たあと。

したがって：

- **やる価値はある。** IGリール用に撮った素材をそのまま投稿できるので、追加コストがほぼゼロ。
  ゼロコストで新しい入口が増えるなら、やらない理由がない。
- **ただし優先順位は3番目。** Instagramの整備と、購入導線（セットページ、サイズガイド、
  在庫の正確さ）のほうが先。**売り切りフェーズでは特にそう。**
- **TikTok単体の売上は期待しない。** 評価はリーチとプロフィールクリックで見る。
  売上で評価すると必ず「効果なし」と誤判定する。
- 新規アカウントの運用工数を1から積むより、**まずIGリールを週2本きちんと出す**ほうが確実。
  リールが安定して回り始めてから、同じ素材をTikTokに流す。

> 結論：**「やるべきだが、いま最優先ではない」。** 順番は
> ①在庫連携の是正 → ②Instagram＋購入導線 → ③TikTokへの横展開。

## 1.5 手持ち素材でいま何ができるか

既存画像166点を棚卸しした結果は `docs/creative-assets-audit-2026-08-30.md`。要点だけ:

- **Google Drive に本格ルックブックが眠っている**（2021-10-31撮影・高解像度10点）。
  80〜90年代アメリカのファミリーポートレート・パロディで、
  **父・息子・母・娘・愛犬が全員お揃いのBritish Dogsシャツを着たヒーローカットがある。**
  これがInstagramにもShopifyにも一切使われていない。**sumif最大の埋もれた資産**
- Shopifyの商品画像では、大人・キッズ・犬が**まったく同じスタジオセット**（白壁・コンクリ床・
  観葉植物・白ベンチ・ムートン・籐椅子）で撮られているが、3者が1枚に収まったカットはない
- 着用カットは **1500×1800（5:6）縦** で、Instagramフィード（4:5）にほぼそのまま載る
- → **カルーセルで「大人→キッズ→犬」と送れば、背景が同じなので疑似的に3者リンクが成立する。**
  切り抜きも合成も不要で、今日から投稿できる

**新規撮影を待たずに始めること。** 撮影は並行して仕込む。

## 2. コンテンツの型（これを回す）

投稿企画に迷ったら、以下の型から選ぶ。型に番号を振ってカレンダーで管理する。

### A. 3者リンクコーデ（週1必須）
大人・キッズ・愛犬が同じ絵柄で並ぶ。sumifの核。
公園・お出かけ先で撮る。1枚目は必ず「3者が画面に収まった引きの絵」。

### B. 2者リンクコーデ
「大人＋愛犬」または「親子」。子どもがいない層への入口。
Bだけで終わらせず、キャプションで「キッズサイズもあります」に触れる。

### C. うちの子紹介 / UGCリポスト
お客様の投稿を許諾を得てリポスト。犬の名前・犬種・エピソードを添える。
**許諾はDMで個別に取る。無断転載しない。**

### D. ディテール解説
プリントの質感、生地、マジックテープ、リブ。マクロ撮影。
「なぜこの値段なのか」に静かに答える回。

### E. サイズ選びガイド
「うちの子の体重◯kgならこのサイズ」。犬の体型別。カルーセルで保存されやすい。
**返品率を下げる実利もある。**

### F. ブランドストーリー / 作り手
アーティストコラボ（NOI、john manami、mirei、The TENT）、シルクスクリーンの制作風景。
動画向き。「アートとの融合」というブランド資産を可視化する。

**2021年のルックブックもこの型で使う**（方針2 / `docs/brand-context.md` 4.5節）。
「sumifのはじまり」として年に数回、文脈を持たせて出す。**通常の商品投稿には混ぜない。**
執筆前に撮影者・コンセプト・モデルの事実確認を必ず行うこと。分からないことは書かない。

### G. 動物愛護・寄付
売上の一部の寄付について。**事実ベースのみ。数字を盛らない。**
年に数回、報告として。頻度を上げるとお為ごかしに見える。

### H. 季節・記念日フック
後述の年間カレンダー参照。

### I. 発売・受注告知
新作、再入荷、受注生産の締切。事実を静かに。煽らない。

## 3. リールの基本構成（15〜30秒）

```
0.0-1.5s  フック：3者が並ぶ画 or 「うちの子とお揃い、できます」のテロップ
1.5-8s    展開：着替え〜並ぶまで / お散歩の道中 / ディテールのアップ
8-20s     情報：シリーズ名、サイズ展開、価格を1回だけ静かに出す
20-30s    締め：家族が歩き去る後ろ姿など、余韻のある画
```

- 1.5秒以内に「犬が服を着ている」ことが分かる画を出す（離脱防止）
- 音は流行曲より、環境音+穏やかなBGMのほうがブランドに合う
- テロップは最小限。文字で説明しすぎない

## 4. ハッシュタグ設計

投稿ごとに **[ブランド] + [カテゴリ] + [犬種/シリーズ] + [コミュニティ]** から10〜15個を組む。
毎回まったく同じセットを貼らない（3〜4パターンをローテーション）。

- **ブランド固定**: `#sumif` `#sumifofficial`
- **カテゴリ**: `#リンクコーデ` `#犬とお揃い` `#親子リンクコーデ` `#愛犬とお揃い` `#ペットとおそろい` `#犬服` `#ドッグウェア`
- **コミュニティ**: `#犬のいる暮らし` `#愛犬との暮らし` `#いぬすたぐらむ` `#dogstagram` `#犬と子ども`
- **犬種**（登場する犬に合わせて可変）: `#トイプードル` `#柴犬` `#コーギー` など
- **シリーズ**: `#britishdogs` `#flanders` `#rintintin` 等

> 犬種タグは**その投稿に実際に写っている犬種のみ**。写っていない犬種のタグを付けない。

## 5. UGC・アンバサダーの回し方

1. **収集**: `#sumif` のメンション・タグ付けを毎週チェック。ストーリーズのメンションも拾う。
2. **許諾**: DMで個別に依頼（テンプレは `sumif-community-manager` が保持）。
3. **リポスト**: 許諾が取れたものをストーリーズ→反応が良ければフィードへ。
4. **アンバサダー化**: 継続的に投稿してくれる飼い主さんに、新作の先行提供を打診。
5. **開示**: 提供を伴う投稿には必ず `#PR` を依頼時点で条件として明示（ステマ規制対応）。

**インフルエンサー選定基準**（フォロワー数より優先すべき順）
1. 愛犬と日常的に写っている（犬だけのアカウントより、飼い主も写るほうが良い）
2. 子どもがいる、または子ども連れの投稿がある（3者リンクの絵が撮れる）
3. 保存・コメントが多い（リーチよりエンゲージ率）
4. 犬種・サイズがsumifの展開（XS〜L）に合う
5. マイクロ（1万〜5万）を複数、が費用対効果が高い

## 6. KPI

| 階層 | 指標 | 見る場所 | 頻度 |
|---|---|---|---|
| **売上** | SNS経由セッション → CVR → 売上 | Shopify分析（流入元別） | 週次 |
| **導線** | プロフィールリンクのクリック数 | 各SNSインサイト | 週次 |
| **エンゲージ** | 保存数（最重要）、シェア数 | 各SNSインサイト | 週次 |
| **リーチ** | リール再生数、フォロワー外リーチ率 | 各SNSインサイト | 週次 |
| **コミュニティ** | UGC件数、`#sumif` 投稿数 | 手動カウント | 月次 |

> **フォロワー数を主要KPIにしない。** アパレルEC、特に単価¥4,000〜12,000の商品では
> 「保存数」と「プロフィールリンククリック」のほうが売上と相関する。
