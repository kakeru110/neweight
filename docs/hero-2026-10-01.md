# トップのヒーローを「家族写真＋コピー」に差し替え（2026-10-01）

## 背景

トップページのファーストビューは **509px（スマホ150px）の帯画像1枚で、文字もリンクも0**だった。
セッションの 35/66 が `/` に着地しているのに、いちばん見られる画面が無言だった。

## 素材調査の結果

現行スタイル（白ホリゾント・2026年撮影）で**大人・キッズ・犬が1枚に入っているカットは
ブリタニースパニエルの1枚しかない**。

| | |
|---|---|
| `bs_family.jpg` / `_k` / `_d` | 同じカットの別バージョン。いずれも 1500×1799 の縦位置 |
| 他シリーズ（British Dogs / RinTinTin / Flanders / Various dogs） | 家族カットなし |
| Drive「ルック」フォルダ | 2021年のレトロstudio撮影。家族＋犬は写っているが系統が違い、子どもの着用品は現行商品ではない |

Driveの `title contains 'family'` では0件。Shopify側のファイル検索でも上記3点のみ。

## 器（スライダー）の制約

いまのヒーローは `sumif.jpg` 1220×508（**2.4:1の横帯**）。
スライダーは1枚ごとに画像＋見出し＋ボタンを持てて高さも選べるが、
**2.4:1に縦位置の家族写真は入らない**（家族の頭も犬も切れる）。

→ スライダーをやめ、**`feature-row`（テキスト付き画像）**をヒーローにした。
縦の写真がそのまま使え、横にコピーとCTAが入る。スマホでは写真→コピーに縦積みされる。

## トリミング → 不採用（2026-10-01 ユーザー判断）

当初は余白が大きいので寄せた切り抜き（855×1494 / 比0.57）を作ったが、
**「切り取るとださくなる」ため切り取りなしに戻した。**

検討した3段階（記録として残す）:

| | 切り抜き範囲 | 出力 | 比 |
|---|---|---|---|
| V1 ひかえめ | x 0.10–0.80 / y 0.11–0.97 | 1050×1548 | 0.68 |
| V2（一度採用） | x 0.17–0.74 / y 0.13–0.96 | 855×1494 | 0.57 |
| V3 しっかり寄せ | x 0.195–0.705 / y 0.12–0.97 | 765×1530 | 0.50 |

寄せると家族は大きくなるが、植物・椅子・床という**写真の構図そのものが壊れる**。
縦に細長くなるぶん左右が詰まり、スタジオ撮影の余白が持っていた落ち着きが消える。

**最終: 元画像のまま（1500×1799 / 比0.834）を使用。**
`fileUpdate` で `sumif_hero_family.jpg` の中身を切り抜き版から元画像に差し替えた
（ファイルIDは `gid://shopify/MediaImage/40679086817518` のまま。
 そのため `config/settings_data.json` は書き換え不要だった）。
元の `bs_family.jpg` も残っている。

## 変更したファイル（ドラフトテーマ `166235046126`）

### 1. `config/settings_data.json`

変更は2か所だけ（変更前後を `docs/data/theme-hero-2026-10-01/` に保存）。

- `sections` に `sumif-hero`（type: `feature-row`）を追加
- `content_for_index` の先頭 `"slider"` を `"sumif-hero"` に差し替え

スライダーのセクション定義そのものは残してあるので、テーマエディタで元に戻せる。

ヒーローの設定値:

| 項目 | 値 |
|---|---|
| 見出し | 大人・キッズ・愛犬で、同じ柄を着る。 |
| 本文 | Sumif は、大人・キッズ・愛犬が同じ絵柄で着られるアパレルブランドです。／※大人・キッズ・ドッグはそれぞれ別売りです。 |
| ボタン | 商品を見る → `/collections/all` |
| 画像の位置 | 左 |

モックでは「シリーズを見る」としていたが、**シリーズ一覧ページは実在しない**ので
「商品を見る」に変えた。シリーズのタイルを作ったら、そこへ向け直す。

### 2. `sections/feature-row.liquid`

PCで画像が列(610px)の中で366pxしかなく、コピーとの間が310px空いていた。

  画像が列をほぼ埋めるようになったため**削除した**。それ以外はテーマ標準のまま

**注意**: このファイルのスキーマにあった多言語ラベルを en / ja だけに整理した。

## ヒーローの文言を修正（2026-10-01）

公開後、「大人・キッズ・愛犬」というワードに違和感があるとの指摘。
調べたところ**ブランド資料の中に答えがあった**。

`docs/brand-context.md` §1 のブランド一行説明は
「**大人・子ども・愛犬**が、同じデザインで一緒に着られる」。
§2 も「家族3者（大人・子ども・愛犬）」。

一方でサイズ表記・商品名は「大人／キッズ／ドッグ」。
**Sumif にはもともと語り用と仕様用の2系統があった**のに、
ヒーローはその2つを混ぜていた（見出しが「キッズ＋愛犬」、注記が「ドッグ」）。
さらに見出しが「同じ**柄**」、本文が「同じ**絵柄**」で揺れていた。

### 検討した見出し5案

| | 案 | 懸念 |
|---|---|---|
| **A（採用）** | 大人・子ども・愛犬で、同じ絵柄を着る。 | 説明的で情緒は薄い |
| B | 愛犬のぶんまで、おそろいがある。 | 大人・子どもが明示されない |
| C | 家族みんなで、同じ絵柄を着る。愛犬も。 | 「みんな」に犬が入ると直感的に伝わらない |
| D | 並んで撮ると、ちゃんと家族に見える。 | 最もトーンに近いが、何を売っているか分からない |
| E | おそろいは、3人と1匹ぶん。 | 「3人」が家族構成を決め打ち。子なし夫婦＋犬のサブ層を外す |

0件58日でファーストビューを情緒に振ると、何が買える店なのか分からないままになるためAを採用。
D は良いコピーなのでシリーズ紹介やSNS側で使う。

### 最終の文言

| | |
|---|---|
| 見出し | 大人・子ども・愛犬で、同じ絵柄を着る。 |
| 本文 | アーティストが描いた犬の絵柄を、大人・子ども・愛犬それぞれのサイズでつくっています。 |
| 注記 | ※大人・キッズ・ドッグはそれぞれ別売りです。 |
| ボタン | 商品を見る → `/collections/all` |

本文は見出しの言い換えをやめ、**アーティストの絵柄**と**3サイズある**という情報を足した。

この使い分けのルールは `docs/brand-context.md` §6 に追記した（今後のコピーで迷わないように）。
