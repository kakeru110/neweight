# トップのヒーローを「家族写真＋コピー」に差し替え（2026-10-01）

## 背景

トップページのファーストビューは **509px（スマホ150px）の帯画像1枚で、文字もリンクも0**だった。
セッションの 35/66 が `/` に着地しているのに、いちばん見られる画面が無言だった。

## 素材調査の結果

現行スタイル（白ホリゾント・2026年撮影）で**大人・キッズ・犬が1枚に入っているカットは
ブリタニースパニエルの1枚しかない**。

| | |
|---|---|
| `bs_family.jpg` / `_k` / `_d` | 同じカットの別バージョン。いずれも 1500×1799 の縦位置 |
| 他シリーズ（British Dogs / RinTinTin / Flanders / Various dogs） | 家族カットなし |
| Drive「ルック」フォルダ | 2021年のレトロstudio撮影。家族＋犬は写っているが系統が違い、子どもの着用品は現行商品ではない |

Driveの `title contains 'family'` では0件。Shopify側のファイル検索でも上記3点のみ。

## 器（スライダー）の制約

いまのヒーローは `sumif.jpg` 1220×508（**2.4:1の横帯**）。
スライダーは1枚ごとに画像＋見出し＋ボタンを持てて高さも選べるが、
**2.4:1に縦位置の家族写真は入らない**（家族の頭も犬も切れる）。

→ スライダーをやめ、**`feature-row`（テキスト付き画像）**をヒーローにした。
縦の写真がそのまま使え、横にコピーとCTAが入る。スマホでは写真→コピーに縦積みされる。

## トリミング

元画像は余白が大きかった（左の観葉植物が幅の26%、右の椅子が36%、上下の壁と床で約20%）。
家族＋犬が占めるのは **x 0.26〜0.64 / y 0.16〜0.93**。

3段階を並べて比較し、**中くらい（V2）** を採用。

| | 切り抜き範囲 | 出力 | 比 |
|---|---|---|---|
| V1 ひかえめ | x 0.10–0.80 / y 0.11–0.97 | 1050×1548 | 0.68 |
| **V2 採用** | **x 0.17–0.74 / y 0.13–0.96** | **855×1494** | **0.57** |
| V3 しっかり寄せ | x 0.195–0.705 / y 0.12–0.97 | 765×1530 | 0.50 |

V3は写真の列が410pxまで細くなって右が空きすぎ、スマホでは男性の腕が枠で切れるため見送り。

書き出したファイル: `sumif_hero_family.jpg`（855×1494 / `gid://shopify/MediaImage/40679086817518`）。
**元の `bs_family.jpg` は消していない。**

## 変更したファイル（ドラフトテーマ `166235046126`）

### 1. `config/settings_data.json`

変更は2か所だけ（変更前後を `docs/data/theme-hero-2026-10-01/` に保存）。

- `sections` に `sumif-hero`（type: `feature-row`）を追加
- `content_for_index` の先頭 `"slider"` を `"sumif-hero"` に差し替え

スライダーのセクション定義そのものは残してあるので、テーマエディタで元に戻せる。

ヒーローの設定値:

| 項目 | 値 |
|---|---|
| 見出し | 大人・キッズ・愛犬で、同じ柄を着る。 |
| 本文 | Sumif は、大人・キッズ・愛犬が同じ絵柄で着られるアパレルブランドです。／※大人・キッズ・ドッグはそれぞれ別売りです。 |
| ボタン | 商品を見る → `/collections/all` |
| 画像の位置 | 左 |

モックでは「シリーズを見る」としていたが、**シリーズ一覧ページは実在しない**ので
「商品を見る」に変えた。シリーズのタイルを作ったら、そこへ向け直す。

### 2. `sections/feature-row.liquid`

PCで画像が列(610px)の中で366pxしかなく中央寄せになり、コピーとの間が310px空いていた。

- 画像の高さ上限を 640 → **720**（画像幅 366 → 412px）
- 画像を列の中央ではなくコピー側へ寄せ、間隔を **50px** に固定（769px以上のときだけ）

**注意**: このファイルのスキーマにあった多言語ラベルを en / ja だけに整理した。
他言語のテーマエディタでは英語表示になる。ストアは日本語運用なので実害はない。
