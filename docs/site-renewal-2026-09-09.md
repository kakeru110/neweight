## ~~🔴 提案1~~：並びの軸を「対象」から「シリーズ」へ変える（↑で実施済み）

**これが一番効く。しかも無料で今日できる。**

### いまの構造の何が問題か

現在のナビは `Adult / Kids / Dog`。**着る人で分かれている。**

でも sumif が売っているのは「大人の服」でも「犬の服」でもなく、
**同じ柄を家族で揃える体験**。いまの構造だと、お客は

1. Adultを開いて柄を見る
2. Kidsを開いて「さっきの柄あるかな」と探す
3. Dogを開いてもう一度探す
4. 3つのカートを別々に入れる

——という**組み立て作業を自分でやらされる**。ブランドの一番の売りが、
サイト上ではどこにも「1つの絵」として現れていない。

### 変更後

ナビの主軸を**シリーズ**にする。

```
British Dogs / RinTinTin / Flanders / Brittany Spaniel / Various dogs
```

各シリーズのページを開くと、**大人・キッズ・犬が並んで出る**。
そのままカートに3点入る。

> コレクション自体は**もう5シリーズ分作ってある**（`docs/tagging.md` のタグ体系で組んである）。
> ナビに出していないだけ。**メニューに追加するだけで今日終わる。**

`Adult / Kids / Dog` は消さずに「誰向けに探す」の副軸としてサブメニューに残す。

## 🔴 提案2：在庫0のSKUを棚から下ろす

151SKU中24が在庫0。売り切りフェーズでは、これは
「人気の証」ではなく**カゴ落ちの原因**でしかない。

- コレクションの並び順を **「在庫あり順」** に固定（Shopify標準機能、設定のみ）
- 在庫0のバリエーションは**選べないようにする**（テーマ設定）
- 商品全体が在庫0になったものは**コレクションから外す**

いまは「クリック → サイズ選択 → 売り切れ」を踏ませている。
在庫が多いものが上に来るだけで、見え方が変わる。

## 提案3：テーマを変える（「変わった」と一番わかる部分）

いまの **Minimal** は Shopify の最初期の無料テーマ。
文字が小さく、余白が少なく、画像が小さい。**服が主役になっていない。**

無料で選べる中では、この2つが sumif に合う：

| テーマ | 向いている理由 |
|---|---|
| **Ride** | 画像がとにかく大きい。柄が主役のブランド向き。切り替えが一番「変わった」と見える |
| **Sense** | 明るく余白が広い。ファミリー向けの柔らかさが出る |

有料（$300前後の買い切り）まで含めるなら **Prestige** / **Impulse** が定番だが、
**まず無料テーマで並びを直してから**でいい。順番を逆にすると、
きれいなガワに壊れた動線が乗るだけになる。

> テーマ変更は**公開せずにプレビューで作れる**。今のサイトは動いたまま、
> 裏で新しいテーマを組んで、完成してから切り替えられる。

## 提案4：トップページの構成を変える

### いまの構成
```
バナー画像
↓
All Items / Adult / Kids / Dog の4タイル
↓
おすすめ商品4点
```

**「何のブランドか」が1画面目でわからない。**
初見の人は4つのタイルを見て「で、何屋さん？」となる。

### 変更案

```
1. ヒーロー：大人・子ども・犬が同じ柄を着ている写真1枚
   コピー：「家族で、おそろい。」＋ボタン「セットで見る」
   ※ここは説明文ではなく、写真1枚で伝える

2. 今週のおそろい ── Brittany Spaniel
   大人 / キッズ / ドッグ を横並び3点。合計金額を出す。
   （在庫217点・4色・欠品ほぼ無し＝いま一番自信を持って推せる）

3. シリーズで選ぶ
   5シリーズをカードで。それぞれ「大人・キッズ・犬」のアイコン付き

4. サイズで迷わせない
   犬のサイズ表（首まわり・着丈・胴まわり）と体重目安を、
   商品ページに行く前にトップに出す
   → 犬服の離脱理由の1位はサイズ不安

5. アートの話
   ネルソン美礼 / norahi / Noi の3名。柄が全部描き下ろしであること
   → ここが「よくある犬服」と差がつく唯一の部分

6. 動物愛護
   ピースワンコ・ジャパンへの寄付（事実ベースで）
```

**2と4が売上に直結する。1と5がブランドを立てる。**

## 提案5：商品ページに「おそろい導線」を入れる

大人のTシャツのページの下に、必ず

> **この柄、家族の分もあります**
> [キッズ 110-130 ¥4,000] [ドッグ XS-L ¥5,500]

を出す。Shopifyの「関連商品」ではなく、**同シリーズの他対象を固定表示**。
タグで組めるので、テーマのセクション追加だけで実装できる。

客単価が1点6,500円 → 3点16,000円になる。
**5件の注文を増やすより、1件の中身を厚くするほうが早い。**

## 提案6：コレクションを19個から8個に整理

いま重複が多い。

| 重複しているもの |
|---|
| `Dog` と `愛犬用ウェア` |
| `Kids` と `キッズ用` |
| `Adult` と `アダルト用` |
| `TOP` `Shirt` `T-shirt` `Sumif` `22 S/S` `ホームページ` — ほぼ機能していない |

**残す8個**：
```
All Items / New
British Dogs / RinTinTin / Flanders / Brittany Spaniel / Various dogs
（＋副軸として Adult / Kids / Dog）
```

日本語ハンドルの3つ（`/collections/キッズ用` など）はURLが
`%E3%82%AD%E3%83%83%E3%82%BA...` と化けるので、統合ついでに解消する。

## 足りないもの（写真）

トップのヒーローに使う **「大人・子ども・犬が同じ柄で並んでいる写真」** が、
撮影素材の中に何枚あるかを確認する必要がある。
Googleドライブの2021ルックブックには3者が1枚に収まったカットがあることは確認済み
（`docs/creative-assets-audit-2026-08-30.md`）だが、
**いま在庫のあるシリーズ（Brittany Spaniel / RinTinTin）での3点並びカット**は未確認。

無ければ、Brittany Spaniel の3点を**物撮りで並べる**だけでも成立する。
モデル撮影より早くて安い。
