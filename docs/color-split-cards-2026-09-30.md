# B（色ごとにカードを分割）の実装

開始: 2026-09-30 / 対象: Shopify `sumif_official`

ユーザー判断: 「色ごとに並べた方が見やすい。商品も多く見える」→ **Bで確定。**

---

## 1. 設計

23商品 → **48カード**（色ごとに1枚）。

| 区分 | 商品数 | カード数 |
|---|---:|---:|
| 2色以上 | 14 | 40 |
| 1色のみ | 6 | 6 |
| 色オプションなし（Various dogs） | 3 | 3 |
| 完売色（British Dogs 長袖Tee 大人 スミクロ） | − | **−1（出さない）** |
| **合計** | 23 | **48** |

### 完売色を出さない判断

British Dogs 長袖Tee 大人 スミクロ は OpenLogi在庫 M=0 / L=0 の完売。
売り切りフェーズで棚が狭いので、**買えないカードに枠を使わない。**
（商品ページ側では色チップに斜線を出して「あったが終わった」ことは伝える）

在庫僅少だが購入可能な色は出す。例: Flanders 長袖Tee 大人 スミクロ（M=1 / L=0）。

## 2. カード画像の作り方

カードは `variant.featured_image` を使う。よって**色バリエーションに着用写真を割り当てる**必要がある。

### 色の自動分類は断念した

胴体の色をサンプリングして色名に寄せる方式を2通り試したが、どちらも実用にならなかった。

| 試した方式 | 失敗の理由 |
|---|---|
| 帯の中央値 | 髪・デニム・影が混ざり、ピンクのTシャツがスミクロに分類された |
| 帯の最頻色（量子化） | 帯の位置が固定なので、バストアップと全身で胴体を外す |

**必要なのは「色ごとに1枚」だけ（48枚）なので、コンタクトシートから目視で選ぶ方式に切り替えた。**
自動分類より確実で、枚数も現実的。

### 選定基準

- 同じモデル・同じセット・同じ引きで色を揃える（横に並べたとき色だけが変わって見える）
- 正面・全身寄り
- 犬商品は同じ犬種・同じポーズを優先

### 切り出し

9/30に確立した規則をそのまま使う。

1. 頭部の肌色検出で**頭の中心を実測**
2. `left = 頭の中心 × 画像幅 − 窓幅 ÷ 2`（頭の中心を画像の中心に）
3. 縦は 頭頂が上から5%、服の裾が86%
4. 比率 5:6（テーマが `object-fit: fill` なので比率がずれると歪む）

## 3. 進捗

### 完了: RinTinTin 半袖Tee アダルト（3色）

| 色 | 元写真 | 新Media ID | 頭の中心 | サイズ |
|---|---|---|---|---|
| ピンク | `1B28C744-…` | 40664797413614 | 0.523 | 926×1111 |
| オフホワイト | `F20DA106-…` | 40664797446382 | 0.513 | 852×1022 |
| スミクロ | `53A0F657-…` | 40664797479150 | 0.429 | 907×1089 |

3枚とも**同じ女性モデル・同じセット・同じ引き**。色だけが違う状態に揃った。

`productVariantsBulkUpdate` で6バリエーション（3色×2サイズ）に割り当て済み。
商品ページで色を選ぶと、平置きではなく**着用写真**に切り替わるようになった。

## 4. テーマ側の実装方針（未着手）

`sections/collection-template.liquid` のループを、商品ごとではなく**色ごと**に回す。

```liquid
{% for product in collection.products %}
  {% assign ci = 色オプションのindex %}
  {% if ci == nil %}
    {% include 'product-grid-item' %}          ← 色なし商品はそのまま1枚
  {% else %}
    {% for c in 色の一覧 %}
      {% if その色に販売可能な在庫がある %}      ← 完売色は出さない
        {% assign featured = product %}
        {% assign card_variant = その色の最初の購入可能バリエーション %}
        {% include 'product-grid-item-color' %} ← 画像とリンクをその色に差し替え
      {% endif %}
    {% endfor %}
  {% endif %}
{% endfor %}
```

注意点:

- 2026-09-23まで入っていた旧アプリ（eosh）のハックは、バリエーションIDを
  **区切りなしで連結した文字列に `contains` で部分一致**させていたため誤爆していた。
  今回はIDの完全一致で組む
- カード名に色を付ける（`商品名 / ピンク`）
- リンクは `?variant=<その色の購入可能なバリエーションID>`
- ページネーションは商品単位（20件）のままなので、1ページのカード数は20〜45枚で変動する
- **公開はユーザー操作。** テーマ公開はMCPの安全ポリシーでブロックされる
