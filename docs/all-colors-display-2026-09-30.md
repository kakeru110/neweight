# 「全色を並べて見せる」手段の調査

実施: 2026-09-30 / 対象: Shopify `sumif_official` / テーマ Minimal（Vintage系）

きっかけ: RinTinTinで絞ったとき、色違いのTシャツが並ばない（1商品1カード＝1色しか見えない）

---

## 1. いまの構造

- 色は **`色` オプションのバリエーション**。商品は分かれていない
- 各色バリエーションに **画像が割り当て済み**（ただし中身は後述）
- テーマは **Minimal**（themeStoreId 380）＝ **Vintage系**。
  OS2.0の「カード内スウォッチ」設定は**存在しない**

### 色数の実態（ACTIVE 23商品）

| 区分 | 商品数 | 色ごとに数えたカード数 |
|---|---:|---:|
| 2色以上 | 14 | 40 |
| 1色のみ | 6 | 6 |
| 色オプションなし（Various dogs 3点） | 3 | 3 |
| **合計** | **23** | **49** |

色数の内訳: 4色＝Brittany Spaniel 3点 / 3色＝RinTinTin 3点・Flanders Tee 3点 /
2色＝British Dogs Tee系 3点・Playing Dog・Two of a kind

売り切れの色は1つだけ（British Dogs 長袖Tee 大人 スミクロ、全サイズ0）。

---

## 2. 重要な発見: バリエーション画像は「平置き」

各色バリエーションに紐づいている画像は、**平置き（畳んだ状態）の商品写真**。
9/29〜9/30に1枚目を着用写真へ差し替えた作業とは別の写真。

- 例: RinTinTin 大人 → オフホワイト `DSC01632` / スミクロ `DSC01701` / ピンク `DSC01699`
  いずれも3000px超の正方形・平置き

**色ごとの着用写真は存在する。ただしバリエーションには紐づいていない。**
RinTinTin 大人の場合、商品メディアの中に

| 色 | 着用写真 |
|---|---|
| ピンク | 女性1枚・男性1枚 |
| オフホワイト | 男性1枚・女性1枚 |
| スミクロ | 女性1枚・男性1枚・愛犬と2枚 |

がある。つまり**色で分割したカードを着用写真で見せることは可能**だが、
そのためには各色バリエーションの画像を着用写真に付け替える作業が要る。

---

## 3. 選択肢

### A. カラースウォッチ（色の丸）— **すでに作成済み・未公開**

2026-09-23に実装済み。`docs/color-swatches-2026-09-23.md` 参照。

- 1商品1カードのまま。カードの下に色の丸を並べる
- 丸を押すとその色の商品ページへ飛ぶ（`?variant=`）
- 全サイズ売り切れの色は斜線
- **Liquidのみ / JS不要 / アプリ不要（月額ゼロ）**
- 旧Globoアプリ（死んだまま毎ページ約201KB読んでいた）を撤去するので**ページが軽くなる**
  - コレクション 305KB → 192KB（−37%）

**2026-09-30に再検証した結果、いまも正常に動作する。**
テーマ `166016680174`「Minimal — カラースウォッチ 2026-09-23」。
RinTinTinのプレビューで色の丸9個（3商品×3色）を確認。Globoの残骸は0。

公開するだけで終わる。**追加作業ゼロ。**

弱点: 色が「点」でしか分からない。Tシャツそのものの色は並ばない。

### B. 色ごとにカードを分割（23商品 → 49カード）

コレクションで**文字どおり全色が並ぶ**。売り切りフェーズでは棚が厚く見える利点もある。

- カード名は「商品名 / ピンク」のように色を付ける
- 押すとその色が選ばれた状態の商品ページへ

**ただし前提として、色ごとの画像を着用写真に付け替える必要がある。**
いまのまま分割すると、9/29〜9/30に直した着用写真の統一が崩れ、
**グリッドが平置き写真に逆戻りする。**

必要な作業: 2色以上の14商品 × 色数 ＝ 40枚。うち14枚は作業済みなので
**残り約26枚**の着用写真の選定と5:6切り出し。
（キッズ・ドッグで全色分の着用写真が揃っているかは未確認。要調査）

注意: 2026-09-23まで入っていた旧アプリ（eosh）のハックがこれに近いことをしていたが、
バリエーションIDの部分一致で判定する作りだったため誤爆し、
商品名が壊れる・無関係な色に分裂する状態だった。実装し直しになる。

### C. 1枚目を色違いのコラージュにする

カードの表示幅は231pxしかない。3〜4色を並べると1色あたり60〜75px。
**判別できない。非推奨。**

### D. 色で絞り込めるようにする

「ピンクだけ見たい」には効くが、**全色を並べる要求には応えない。**
Minimalはタグ絞り込み（`collection-tags`）を持っているので、
色タグを付ければ実装はできる。Aの補助として。

---

## 4. 推奨

**A（スウォッチ）をまず公開する。作業ゼロで今日出せる。**

そのうえで B をやるかどうかは、約26枚の写真差し替えに見合うかの判断。
売り切りフェーズで在庫を捌く目的なら、Bの「棚が厚く見える」効果は無視できない。

AとBは排他ではない。**A → B の順に積める。**

### 公開できなかった理由

`themePublish` と `themeFilesUpsert`（ライブテーマ宛）は、いずれも
**MCPサーバーの安全ポリシーでブロックされる。**

```
themePublish   → "Publishing a theme is blocked — making a theme live
                  must be done manually in Shopify admin"
themeFilesUpsert → "This mutation targets the live (published) theme.
                  Theme file writes against the live storefront are blocked."
```

ストアへの書き込み常時承認（2026-09-09）は商品・在庫・価格などのデータに対するもので、
**テーマの公開だけは別枠でブロックされている。** 迂回手段はない。

## 6. Google Drive の確認（2026-09-30）

Aの公開が反映されたことを確認（`themes(roles:MAIN)` = 「Minimal — カラースウォッチ 2026-09-23」）。
そのうえで「Shopifyに未登録の写真がDriveにないか」を確認した。

### Driveの構成

```
マイドライブ/
  sumif写真/                     ← これがsumifの写真フォルダ
    商品画像/                    ← 商品ごとに23フォルダ
      RinTinTin Adult/ ...       ← UUID名のJPG（更新日 2022-12-24）
      22AW-1〜3.jpg              ← 2022秋冬のルック（2022-09-23）
    画像関係/
      物撮り切り抜き/            ← 2021年のPSD（線画・プリント版下）。写真ではない
      TOP画像 / その他画像 / HP用画像 / 撮影資料
    jpeg/
```

（`01_写真` `カメラマン撮影写真（初回）` `採用写真` は **民泊事業**のフォルダで、sumifとは無関係）

### 判明したこと

| 確認 | 結果 |
|---|---|
| Drive全体で `DSC*` の画像 | **0件** |
| Drive全体で 2023-01-01 以降の画像 | sumif関連は**0件**（民泊とPhotoACの素材のみ） |
| `商品画像/` の中身 | すべて更新日 **2022-12-24**＝2022年の撮影分 |
| `物撮り切り抜き/` | 2021年のPSD（デザイン版下）。着用写真ではない |

**Shopifyにある新しい撮影分（`DSC016xx`/`DSC017xx`、`sm1_*`、`IMG_4xxx`/`IMG_5xxx`、
`R_IMG_*`、`bd_*`/`rt_*`/`fl_*`/`bs_*`/`vd_*`）は、Driveには一切ない。**
これらはDriveを経由せず直接Shopifyに上がっている。

### 確認しきれなかった点（正直に記載）

Driveの2022年分のファイル名（例 RinTinTin Adult の `D0A1DCA1-…`）は、
**Shopifyにある同じ商品の2022年分のファイル名（`1B28C744-…` 等）とひとつも一致しない。**

- iPhoneから書き出すたびにUUIDが振り直されるため、**同じ写真の別書き出しである可能性が高い**
- 枚数も近い（RinTinTin Adult: Drive 5枚以上 / Shopify 6枚）
- ただし**中身を開いて確認はしていない。** 画像をこのセッションに取り込むと
  1枚あたり数十万トークンを消費するため、実行しなかった

断定はできないので「ほぼ同じものと思われるが未確認」と記録する。

### Bへの影響: なし

Bに必要なのは**色ごとの着用写真**だが、それは**すでにShopify側にある**。
（RinTinTin 大人では ピンク/オフホワイト/スミクロ の着用写真を9/30に確認済み）

Bの障害は「写真がない」ことではなく、**「写真が色バリエーションに紐づいていない」**こと。
Driveから追加登録する必要はない。
