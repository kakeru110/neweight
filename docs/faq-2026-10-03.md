# FAQをネイティブページで作り直した（2026-10-03）

## 何がしょぼかったか

FAQはアプリ（アプリプロキシ `/apps/frequently-asked-questions`）で作られていて、
**記事が3本しかなかった。**

| セクション | 中身 |
|---|---|
| 支払い方法 | 支払い方法の列挙（1問） |
| ■ ご注文とご配送 | 発送日数／送料（2問） |
| ■ お問合せ先 | チャット・メール・電話（1問） |

**ストアのポリシーに書いてある重要な条件が、FAQに1つも載っていなかった。** 特にこれ:

> 安全衛生の問題から、ドッグウエアは返品交換の対象外となります。

愛犬用が売上の大きな割合を占めるのに、返品できないことがFAQから分からない状態だった。

## やったこと

**ネイティブページ `/pages/faq`（よくあるご質問）を新規作成。**
アプリに依存しない。JavaScriptも使っていない（`<details>` のみ）。

- **8カテゴリ・24問**
- サイズについて（4）／配送・送料（5）／お支払い（2）／返品・交換（4）
  ／商品について（4）／セールについて（3）／動物保護（1）／お問い合わせ（1）
- アコーディオン（クリックで開閉）。`<details>` なのでJS不要・検索エンジンにも読まれる

### 内容はすべて実在のポリシーから取った

| 項目 | 出典 |
|---|---|
| 送料490円／8,000円以上無料／海外1,200円 | 配送ポリシー・利用規約・特商法 |
| 翌日までに発送（12:30までは当日・日祝除く） | 同上 |
| ヤマト運輸・発送後の問い合わせ先 | 利用規約 |
| 長期不在時のキャンセルと3,150円 | 配送ポリシー・利用規約 |
| 返品7日以内・未使用のみ | 返金ポリシー |
| **ドッグウェアは返品交換の対象外** | 返金ポリシー・特商法 |
| 返品不可の4条件 | 返金ポリシー |
| 返品送料の負担・返金7日以内 | 返金ポリシー |
| 支払い方法 | 特商法・お支払い方法ページ |
| 犬の体重目安 XS3-4 / S4-5 / M5-8 / L8-12kg | 公式カタログ 22AW p10 |
| 素材（綿100% / ポリエステル100%） | 各商品ページ |
| 寄付先（ピースワンコ・ジャパン） | 既存ページ。**金額・割合は書いていない** |
| セール 10月31日まで・最大50%OFF | 今回のセール設定 |

### リンクの付け替え

ナビの「ガイド」とフッターの該当項目を、アプリのURLから `/pages/faq` に変更。
ナビでは「FAQ」→「よくあるご質問」に改名し、ガイドの先頭に移した。

**アプリのURLはどこからもリンクされていない状態になった。**
動作を確認のうえ、FAQアプリはアンインストールしてよい。

## 直した誤記

`/pages/payment` の仮想通貨の記載が **「COGE」** になっていた（正しくは **DOGE**）。
特定商取引法に基づく表記のほうは DOGE と書かれていたので、そちらに合わせた。
あわせて、お支払い方法ページの末尾に「よくあるご質問」へのリンクを足した。

## 確認結果の反映（2026-10-03 ユーザー回答）

| 項目 | 回答 | 対応 |
|---|---|---|
| 代金引換 | **なし** | 支払い方法の回答に「代金引換はご利用いただけません」と明記 |
| 発送リードタイム（翌日までに発送／12:30まで当日） | **正しい** | そのまま掲載 |
| ギフトラッピング | **なし** | 「ギフトラッピングはできますか？」を追加し、ご用意がない旨を回答 |

旧FAQアプリに載っていた「代金引換」は、特商法・お支払い方法ページのどちらにも
記載がなく、**実際に提供していない**ことが確認できた。アプリ側の記載が古かった。

## セール関連の質問を削除した（2026-10-03 ユーザー指摘）

> faqにセールはいつまで？なんてあるわけない。ありえるものだけ書いて

初版では「セールについて」というカテゴリを立てて3問入れていたが、
**FAQで「セールはいつまでですか」と検索する人はいない。**告知バーとバナーに書いてある。
期間限定の情報を恒久的なFAQに置くこと自体も誤りだった（終わったら嘘になる）。

| 削除 | 理由 |
|---|---|
| セールはいつまでですか？ | 告知バーに出ている。期間が変われば嘘になる |
| セール品も返品できますか？ | 返品条件は通常と同じ。「返品・交換」の項目で足りる |

**「売り切れた商品は再入荷しますか？」だけは残して「商品について」へ移した。**
これはセールと関係なく聞かれる質問で、売り切りフェーズの事実としても書いておく必要がある。

あわせて、残りの質問も**実際に客が打ちそうな言い回し**に直した。

| 変更前 | 変更後 |
|---|---|
| いつ発送されますか？ | 注文してからどのくらいで届きますか？ |
| 海外から注文できますか？ | 海外に送ってもらえますか？ |
| 受け取れなかった場合はどうなりますか？ | 不在で受け取れなかった場合はどうなりますか？ |
| お手入れ方法を教えてください | 洗濯はできますか？ |
| 素材を教えてください | 素材は何ですか？ |
| 大人用のサイズ選びで迷っています | 大人用は大きめのつくりですか？ |
| タンクトップ・シャツ・スウェットで、同じサイズ表示なら同じ大きさですか？ | 商品によってサイズ感は違いますか？ |
| 寄付について教えてください | 売上の一部が寄付されると聞きました。寄付先はどこですか？ |
| 返品の送料は誰が負担しますか？いつ返金されますか？ | 2問に分割（送料／返金時期） |
